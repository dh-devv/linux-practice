## 1. 터미널 프롬프트 이해하기

예시:

```text
dh@dh-VMware-Virtual-Platform:/$
```

| 구성 요소 | 의미 |
|---|---|
| `dh` | 현재 접속한 사용자 계정 |
| `dh-VMware-Virtual-Platform` | 컴퓨터 이름 또는 `hostname` |

> **EXAM POINT**

> - `#`는 `root` 사용자를 의미한다.

## 2. 슈퍼유저와 사용자 전환

### 슈퍼유저란?

Linux와 같은 Unix 계열 운영체제에서 시스템 전체를 관리할 수 있는 관리자 계정이다.

Linux의 관리자 계정은 일반적으로 `root`라고 한다.

주요 관리 업무는 다음과 같다.

1. 사용자 등록 및 삭제
2. 소프트웨어 설치·업그레이드·삭제
3. 하드웨어 추가 및 설정
4. 시스템 보안 관리
5. 데이터 백업

### `sudo`

일반 사용자가 특정 명령어를 일시적으로 관리자 권한으로 실행할 때 사용한다.

```bash
sudo command
```

예시:

```bash
sudo apt update
```

### `passwd`

사용자의 비밀번호를 설정하거나 변경한다.

```bash
passwd
sudo passwd username
```

### `su`

다른 사용자 계정으로 전환한다.

```bash
su username
```

`root` 계정으로 전환하는 방법:

```bash
su -
su root
```

`su -`는 대상 사용자의 로그인 환경까지 적용하여 전환하는 방식이다.

Ubuntu에서는 `root` 계정이 잠겨 있는 경우가 많다. 이때는 다음 명령어를 사용할 수 있다.

```bash
sudo -i
```

`sudo -i`는 현재 사용자의 `sudo` 권한을 이용하여 `root` 셸을 실행한다.

현재 셸이나 사용자 전환을 종료하고 이전 사용자로 돌아가기:

```bash
exit
```

> **EXAM POINT**
>
> - `su -i`는 일반적인 사용자 전환 명령어가 아니다.
> - 로그인 환경까지 적용하여 `root`로 전환할 때는 `su -`를 사용한다.
> - Ubuntu에서 `root` 계정이 잠겨 있으면 `sudo -i`를 사용할 수 있다.

## 3. Linux의 파일 종류

Linux에서는 디렉터리와 장치도 파일의 한 종류로 관리한다.

| 파일 종류 | 설명 | 예시 또는 위치 |
|---|---|---|
| 일반 파일 | 디스크에 저장되는 대부분의 파일 | 텍스트, 이미지, 동영상, 실행 파일 |
| 디렉터리 | 파일과 하위 디렉터리를 관리하는 특수 파일 | `/home` |
| 심볼릭 링크 | 다른 파일이나 디렉터리를 가리키는 경로 | `bin -> usr/bin` |
| 장치 파일 | 하드웨어 장치를 파일처럼 표현한 특수 파일 | `/dev` |

### 일반 파일

사용자가 주로 사용하는 대부분의 파일이 일반 파일이다.

#### 텍스트 파일

파일의 내용이 사람이 읽을 수 있는 문자로 구성된 파일이다.

예시:

- 소스 코드
- 설정 파일
- 일반 문서 파일

#### 이진 파일

텍스트가 아닌 형태의 데이터로 구성된 파일이다.

예시:

- 실행 파일
- 이미지
- 동영상
- 일부 문서 파일

> **EXAM POINT**
>
> 텍스트 파일과 이진 파일은 모두 일반 파일에 해당한다.

### 디렉터리

파일과 하위 디렉터리를 계층적으로 관리하는 특수 파일이다.

디렉터리에는 해당 디렉터리에 포함된 파일과 하위 디렉터리의 이름 및 위치 정보가 저장된다.

### 심볼릭 링크

다른 파일이나 디렉터리를 가리키는 별도의 경로이다.

Windows의 바로 가기와 비슷한 기능을 한다.

예시:

```text
bin -> usr/bin
```

심볼릭 링크는 원본 파일의 복사본이 아니라 원본을 가리키는 경로를 저장한다.

### 장치 파일

하드디스크, 키보드, 마우스, DVD 드라이브 등 시스템 장치를 파일처럼 표현한 특수 파일이다.

장치 파일은 주로 다음 디렉터리에 존재한다.

```text
/dev
```

## 4. Ubuntu Linux 디렉터리 구조

| 디렉터리 | 설명 |
|---|---|
| `/` | 최상위 디렉터리. 모든 디렉터리의 시작점 |
| `/bin` | `ls`, `mv`, `cp`와 같은 기본 명령어가 저장되는 디렉터리 |
| `/boot` | 부팅에 필요한 파일과 부트로더 관련 파일이 저장되는 디렉터리 |
| `/dev` | 하드디스크, 키보드, 마우스 등 장치 파일이 저장되는 디렉터리 |
| `/home` | 일반 사용자들의 홈 디렉터리가 저장되는 디렉터리 |
| `/lib` | 프로그램 실행에 필요한 공유 라이브러리가 저장되는 디렉터리 |
| `/mnt` | 파일 시스템을 임시로 마운트할 때 사용하는 디렉터리 |
| `/media` | USB와 같은 이동식 장치가 자동으로 마운트되는 위치 |
| `/opt` | 추가로 설치한 응용 프로그램을 저장하는 디렉터리 |
| `/root` | `root` 사용자의 홈 디렉터리 |
| `/var` | 로그, 캐시 등 자주 변경되는 데이터가 저장되는 디렉터리 |

> 최신 Ubuntu에서는 `/bin`이 `/usr/bin`을 가리키는 심볼릭 링크이고, `/lib`도 `/usr/lib`와 연결된 경우가 있다.

### `GRUB`

`GRUB`는 `GRand Unified Bootloader`의 약자이다.

Linux에서 널리 사용하는 부트로더이며, 운영체제의 부팅 과정에서 커널을 불러오는 역할을 한다.

여러 운영체제가 설치된 경우 부팅할 운영체제를 선택하는 메뉴를 제공할 수도 있다.

### 홈 디렉터리

사용자가 로그인하면 일반적으로 자신의 홈 디렉터리에서 작업을 시작한다.

사용자 계정이 `dh`라면 홈 디렉터리는 보통 다음과 같다.

```text
/home/dh
```

홈 디렉터리를 사용하는 이유는 다음과 같다.

1. 사용자별 작업 공간을 제공한다.
2. 사용자 간 파일과 권한을 분리한다.
3. 시스템 파일을 보호한다.

현재 사용자의 홈 디렉터리로 이동:

```bash
cd ~
```

다음 명령어도 현재 사용자의 홈 디렉터리로 이동한다.

```bash
cd
```

> **EXAM POINT**
>
> 새로운 사용자를 생성하면 일반적으로 사용자 계정명과 같은 홈 디렉터리가 생성된다.

## 5. 절대 경로와 상대 경로

### 절대 경로

최상위 디렉터리 `/`부터 시작하여 파일이나 디렉터리의 위치를 정확하게 나타내는 방식이다.

예시:

```bash
cd /etc/network
cd /etc/gdb/gdbinit.d
```

절대 경로는 현재 위치와 관계없이 항상 같은 대상을 가리킨다.

### 상대 경로

현재 작업 중인 디렉터리를 기준으로 위치를 나타내는 방식이다.

예시:

```bash
cd etc/network
cd gdb/gdbinit.d
```

위 명령어는 현재 디렉터리 안에 `etc` 또는 `gdb` 디렉터리가 있을 때만 정상적으로 실행된다.

### 특수 경로 기호

| 기호 | 의미 |
|---|---|
| `.` | 현재 디렉터리 |
| `..` | 부모 디렉터리 또는 상위 디렉터리 |
| `~` | 현재 사용자의 홈 디렉터리 |

예시:

```bash
cd ../..
mv test_file .
```

`cd ../..`는 상위 디렉터리로 두 번 이동한다.

`mv test_file .`은 `test_file`을 현재 디렉터리로 이동한다.

## 6. 기본 디렉터리 명령어

### `mkdir`

새 디렉터리를 생성한다.

```bash
mkdir directory_name
```

### `rmdir`

비어 있는 디렉터리를 삭제한다.

```bash
rmdir directory_name
```

`rmdir`은 디렉터리가 비어 있을 때만 사용할 수 있다.

디렉터리 안에 파일이나 하위 디렉터리가 있으면 다음과 같은 오류가 발생한다.

```text
Directory not empty
```

비어 있지 않은 디렉터리는 `rm -r`로 삭제할 수 있다.

```bash
rm -r directory_name
```

> `rm -r`은 디렉터리 안의 파일과 하위 디렉터리까지 삭제할 수 있으므로 주의해야 한다.

### `ls`

현재 디렉터리 또는 지정한 경로의 내용을 출력한다.

```bash
ls
ls path
```

## 7. Linux 명령어 옵션

Linux 명령어의 옵션은 크게 두 가지 형식이 있다.

| 옵션 종류 | 형식 | 예시 |
|---|---|---|
| 짧은 옵션 | 하이픈 하나 `-` | `ls -l` |
| 긴 옵션 | 하이픈 두 개 `--` | `adduser --uid 1001 username` |

짧은 옵션은 여러 개를 붙여서 사용할 수 있다.

```bash
ls -al
```

### `ls`의 주요 옵션

| 옵션 | 설명 |
|---|---|
| `-a` | 숨김 파일을 포함하여 모든 파일 출력 |
| `-l` | 파일의 상세 정보 출력 |
| `-R` | 하위 디렉터리까지 재귀적으로 출력 |
| `-al` | 숨김 파일을 포함하여 상세 정보 출력 |

예시:

```bash
ls -a
ls -l
ls -al
ls -R
```

### `adduser`에서 사용자 ID 지정하기

사용자 ID를 지정할 때는 `--uid` 옵션을 사용한다.

```bash
adduser --uid 1001 username
```

> `adduser dh --git 1001`은 사용자 ID를 지정하는 올바른 일반 문법이 아니다.

## 8. 숨김 파일

Linux에서는 파일명이나 디렉터리명의 첫 글자가 마침표(`.`)이면 숨김 파일로 취급한다.

예시:

```text
.bashrc
.profile
```

숨김 파일을 확인하려면 `-a` 옵션을 사용한다.

```bash
ls -a
```

## 9. 오류 메시지

### `Permission denied`

현재 사용자에게 해당 작업을 수행할 권한이 없다는 뜻이다.

관리자 권한이 필요한 경우 다음과 같이 실행할 수 있다.

```bash
sudo command
```

### `Directory not empty`

삭제하려는 디렉터리 안에 파일이나 하위 디렉터리가 있다는 뜻이다.

`rmdir`은 빈 디렉터리만 삭제할 수 있다.

## 10. 명령어 설명서 확인하기

### `man`

`man`은 명령어의 설명서와 사용 방법을 확인하는 명령어이다.

```bash
man command
```

예시:

```bash
man ls
```

`man ls`에서는 `ls` 명령어의 기능과 옵션을 확인할 수 있다.

설명서를 종료하려면 다음 키를 누른다.

```text
q
```

> **EXAM POINT**
>
> `man [command]`는 해당 명령어의 설명, 사용법, 옵션을 확인하는 명령어이다.
