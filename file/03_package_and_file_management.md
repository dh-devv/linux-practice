# 패키지 및 파일 관리

## 1. 라이브러리와 패키지

### 라이브러리

라이브러리는 프로그램이나 다른 코드를 만들 때 가져다 사용할 수 있도록 미리 만들어 둔 코드의 집합이다.

### 패키지

라이브러리나 프로그램을 다른 사람이 쉽게 설치하고 사용할 수 있도록 관련 파일과 정보를 하나로 묶어 포장한 것이다.

---

## 2. 패키지 매니저

패키지 매니저는 인터넷 저장소에서 프로그램이나 라이브러리를 찾아 자동으로 설치, 삭제, 업데이트하는 도구이다.

### 패키지 매니저가 필요한 이유

* 새로운 소프트웨어나 라이브러리를 쉽게 설치할 수 있다.
* 프로그램이 필요로 하는 의존 패키지를 함께 설치할 수 있다.
* 설치된 패키지의 업데이트를 관리할 수 있다.
* 패키지를 일관된 방식으로 설치하고 삭제할 수 있다.
* 의존성 문제를 줄일 수 있다.

### Ubuntu와 CentOS의 패키지 매니저

| 운영체제 | 대표 명령어 |
|---|---|
| Ubuntu | `apt` |
| CentOS | `yum` |
| 최신 CentOS 및 RHEL 계열 | `dnf` |

### `dpkg`와 `apt`의 차이

| 명령어 | 설명 |
|---|---|
| `dpkg` | 개별 `.deb` 패키지를 직접 설치하고 삭제하는 저수준 도구 |
| `apt` | 패키지와 관련된 의존 패키지를 함께 찾아 관리하는 고수준 도구 |

> **EXAM POINT**
>
> `dpkg`를 사용하면 필요한 의존 패키지를 직접 준비해야 할 수 있다.  
> `apt`를 사용하면 의존 패키지를 자동으로 확인하고 함께 설치할 수 있다.

### `apt update`

설치 가능한 패키지 목록을 최신 상태로 갱신한다.

실제 설치된 패키지의 버전을 업데이트하는 명령어는 아니다.

```bash
sudo apt update
```

### `apt upgrade`

현재 설치된 패키지를 최신 버전으로 업그레이드한다.

```bash
sudo apt upgrade
```

운영 중인 시스템에서는 업데이트로 인한 버전 호환성 문제를 확인한 후 실행해야 한다.

## 3. 명령어 경로 확인

### `which`

실행 가능한 명령어의 경로를 확인한다.

```bash
which ls
which python3
```

예를 들어 다음과 같이 출력될 수 있다.

```text
/usr/bin/ls
```

## 4. 파일과 디렉터리 복사

### `cp`

파일이나 디렉터리를 복사한다.

```bash
cp source_file destination_file
```

예시:

```bash
cp test.txt copy_text.txt
```

위 명령어는 `test.txt`를 `copy_text.txt`라는 이름으로 복사한다.

특정 디렉터리에 파일을 복사할 수도 있다.

```bash
cp test.txt /test/copy/
```

이 경우 `/test/copy/` 디렉터리 안에 `test.txt`가 복사된다.

### `cp -r`

디렉터리와 하위 디렉터리 및 파일을 모두 복사한다.

```bash
cp -r directory_name /test/copy/
```

### `cp -i`

대상 파일이 이미 존재할 경우 덮어쓸지 확인하는 대화형 옵션이다.

```bash
cp -i source_file destination_file
```

| 입력 | 동작 |
|---|---|
| `y` | 덮어쓰기 |
| `n` | 덮어쓰지 않고 건너뛰기 |

### 여러 파일 복사하기

여러 개의 파일을 하나의 디렉터리에 복사할 수 있다.

```bash
cp cs1.txt cs2.txt /target/path/
```

> 여러 파일을 복사할 때 마지막 인자는 반드시 대상 디렉터리여야 한다.

## 5. 파일 이름 변경 및 이동

### `mv`

파일이나 디렉터리의 이름을 변경하거나 다른 위치로 이동한다.

### 파일 이름 변경

```bash
mv cs2.txt cs3.txt
```

위 명령어를 실행하면 `cs2.txt`의 이름이 `cs3.txt`로 변경된다.

이후에는 원래 이름인 `cs2.txt`가 존재하지 않는다.

### 파일 이동

```bash
mv cs3.txt directory_name/
```

위 명령어는 `cs3.txt`를 `directory_name/` 디렉터리로 이동한다.

## 6. 파일과 디렉터리 삭제

### `rm`

지정한 파일을 삭제한다.

```bash
rm test1.txt
```

`rm`으로 삭제한 파일은 일반적으로 휴지통으로 이동하지 않으므로 주의해야 한다.

### `rm` 주요 옵션

| 옵션 | 설명 |
|---|---|
| `-r` | 디렉터리와 하위 내용을 재귀적으로 삭제 |
| `-f` | 확인 과정 없이 강제로 삭제 |
| `-i` | 삭제할 때마다 사용자에게 확인 |
| `-rf` | 디렉터리와 내부 내용을 강제로 삭제 |

예시:

```bash
rm -r directory_name
rm -i test.txt
rm -ri directory_name
```

`rm -ri`를 사용하면 하위 파일과 디렉터리를 삭제할 때마다 확인한다.

| 입력 | 동작 |
|---|---|
| `y` | 삭제 |
| `n` | 삭제하지 않고 건너뛰기 |

> **주의**
>
> `rm -rf`는 매우 위험한 명령어이다. 대상 경로를 정확히 확인한 후 사용해야 한다.

## 7. 파일 압축

### `zip`

파일이나 디렉터리를 `.zip` 형식으로 압축한다.

### 파일 압축

```bash
zip test.zip test.txt
```

여러 파일을 하나의 압축 파일로 만들 수 있다.

```bash
zip multi_file.zip copy_test.txt test.txt
```

### 디렉터리 압축

```bash
zip -r copy.zip copy
```

`-r` 옵션은 디렉터리 내부의 하위 내용까지 포함하여 압축한다.

### 비밀번호를 설정하여 압축

```bash
zip -e secure.zip test.txt
```

`-e` 옵션을 사용하면 압축 파일에 비밀번호를 설정할 수 있다.

### `zip` 주요 옵션

| 옵션 | 설명 |
|---|---|
| `-r` | 디렉터리와 하위 내용을 포함하여 압축 |
| `-e` | 비밀번호를 설정하여 압축 |

---

## 8. 압축 해제

### `unzip`

`.zip` 파일의 압축을 해제한다.

```bash
unzip test.zip
```

### 지정한 디렉터리에 압축 해제

```bash
unzip test.zip -d target_directory
```

`-d` 옵션은 압축을 해제할 대상 디렉터리를 지정한다.

### 압축 파일 목록 확인

```bash
unzip -l test.zip
```

> 압축 파일의 목록을 확인할 때는 `unzip -l`을 사용한다.  
> `unzip -i`는 일반적인 압축 파일 목록 확인 옵션이 아니다.

### 파일 덮어쓰기 선택지

압축을 해제할 때 같은 이름의 파일이 이미 존재하면 다음과 같은 선택지가 표시될 수 있다.

```text
replace test.txt? [y]es, [n]o, [A]ll, [N]one, [r]ename:
```

| 입력 | 동작 |
|---|---|
| `y` | 현재 파일을 덮어씀 |
| `n` | 덮어쓰지 않고 건너뜀 |
| `r` | 현재 파일의 이름을 변경하여 압축 해제 |
| `A` | 이후 겹치는 모든 파일을 묻지 않고 덮어씀 |
| `N` | 이후 겹치는 모든 파일을 덮어쓰지 않음 |

| `unzip` | 압축 해제 |
| `unzip -l` | 압축 파일 목록 확인 |
