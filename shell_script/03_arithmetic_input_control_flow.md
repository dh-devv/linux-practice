# Bash 산술 연산, 입력과 제어문

이 문서는 Bash 스크립트에서 정수 계산, 사용자 입력, 주석, 조건문과 반복문을 사용하는 방법을 정리합니다. POSIX 셸과 Bash는 문법과 기능이 다를 수 있으므로, 예제는 `#!/bin/bash`로 실행하는 Bash 기준입니다.

## 변수와 상수

Bash 변수는 일반적인 프로그래밍 언어처럼 정수·문자열 자료형을 미리 선언하지 않습니다. 보통 변수에는 문자열 형태의 값이 저장되지만, 산술 문맥에서는 값을 정수로 해석합니다. 따라서 “변수는 문자열이므로 숫자 계산을 할 수 없다”기보다 **계산할 때 산술 문맥을 사용한다**고 이해하면 됩니다.

```bash
number=3
echo "number = ${number}"
```

값 변경을 막으려면 `readonly` 또는 `declare -r`를 사용합니다. 선언 뒤에는 값을 다시 대입하거나 `unset`할 수 없습니다.

```bash
readonly MAX_RETRY=3
declare -r APP_NAME="linux-practice"
```

`declare -i`는 변수에 정수 속성을 지정합니다. 이후 대입되는 값도 산술식으로 평가됩니다. 단순한 계산에는 보통 `$(( ))`를 직접 사용하면 충분합니다.

```bash
declare -i number
number=1+2
echo "number = ${number}"  # 3
```

## 정수 산술

### 산술 확장 `$(( ))` — Bash에서 권장

Bash의 산술 확장은 정수 계산 결과를 문자열로 확장합니다. 산술식 안에서는 변수명 앞에 `$`를 붙이지 않아도 됩니다. 나눗셈 결과는 정수이며 소수 부분은 버려집니다.

```bash
#!/bin/bash

num1=200
num2=100

echo "덧셈: $((num1 + num2))"
echo "뺄셈: $((num1 - num2))"
echo "곱셈: $((num1 * num2))"
echo "나머지: $((num1 % num2))"
echo "몫: $((num1 / num2))"
```

`$(( ))` 안에서는 `+`, `-`, `*`, `/`, `%`를 일반적인 산술 연산자로 사용합니다. 0으로 나누면 오류가 납니다. 셸 산술은 정수 계산이므로 소수 계산에는 별도 도구가 필요합니다.

### `expr` 명령

`expr`은 별도의 명령으로 식을 계산합니다. 인자 사이에 공백을 두어야 하며, `*`는 셸의 파일명 패턴 확장을 피하도록 `\*`처럼 이스케이프합니다. Bash 스크립트에서는 대체로 외부 명령 실행이 필요 없는 `$(( ))`가 더 간결합니다.

```bash
num1=200
num2=100

sum=$(expr "$num1" + "$num2")
product=$(expr "$num1" \* "$num2")
remainder=$(expr "$num1" % "$num2")
quotient=$(expr "$num1" / "$num2")

printf '합: %s, 곱: %s, 나머지: %s, 몫: %s\n' \
  "$sum" "$product" "$remainder" "$quotient"
```

명령 치환은 오래된 백틱 `` `명령` ``보다 `$(명령)` 표기를 권장합니다. 중첩하기 쉽고 읽기 편합니다.

## 사용자 입력: `read`

`read`는 표준 입력에서 한 줄 또는 지정한 길이의 입력을 변수에 저장합니다. `-p`는 안내 문구, `-s`는 터미널 입력 숨김, `-n N`은 최대 N자를 읽으면 줄 끝을 기다리지 않고 반환하는 옵션입니다. `-n`은 입력이 먼저 줄 끝에 도달하면 N자보다 적게 읽을 수도 있습니다.

```bash
#!/bin/bash

read -r -p "아이디 입력 >> " user_id
read -r -s -p "비밀번호 입력 >> " password
printf '\n'
read -r -n 5 -p "닉네임(최대 5자) >> " nickname
printf '\n'

printf '아이디: %s\n' "$user_id"
printf '닉네임: %s\n' "$nickname"
```

`-r`은 입력에 포함된 백슬래시를 이스케이프 문자로 처리하지 않게 합니다. 입력을 그대로 받으려면 함께 사용하는 습관이 좋습니다. `-s`는 비밀번호를 저장하거나 암호화하지 않고, 터미널에 입력 문자가 표시되는 것만 막습니다.

## 주석

한 줄 주석은 `#`으로 시작합니다. 단, `#!/bin/bash`는 스크립트를 실행할 인터프리터를 지정하는 셔뱅(shebang)입니다.

```bash
# 한 줄 설명
echo "실행됩니다"  # 명령 뒤 설명
```

Bash에는 전용 여러 줄 주석 문법이 없습니다. 다음처럼 인용한 here-document를 `:` 명령에 연결해 내용을 무시하게 만들 수는 있지만, 이것은 문법상 주석이 아니라 **빈 명령이 입력을 소비하는 방식**입니다. 종료 표식은 단독 행에 둡니다.

```bash
: <<'COMMENT'
여러 줄 설명을 여기에 적습니다.
인용한 표식이므로 본문에서 변수나 명령 치환을 하지 않습니다.
COMMENT
```

## 조건문

### `[` 테스트 명령

대괄호 방식은 `[ 조건식 ]` 전체가 명령이므로 대괄호 안팎에 공백이 필요합니다. 숫자를 비교할 때는 `-eq`, `-ne`, `-lt`, `-le`, `-gt`, `-ge`를 사용합니다. 변수는 따옴표로 감싸면 값이 비어 있거나 공백이 있어도 안전합니다.

| 연산자 | 의미 |
| --- | --- |
| `-eq` | 같다 |
| `-ne` | 같지 않다 |
| `-lt` / `-le` | 작다 / 작거나 같다 |
| `-gt` / `-ge` | 크다 / 크거나 같다 |

```bash
num1=10
num2=20

if [ "$num1" -eq "$num2" ]; then
  echo "두 수는 같다."
elif [ "$num1" -gt "$num2" ]; then
  echo "첫 번째 수가 더 크다."
else
  echo "첫 번째 수가 더 작다."
fi
```

### 산술 조건식 `(( ))`

`(( ))`는 Bash의 산술 조건식입니다. 변수명에 `$`를 붙이지 않고, 일반 산술식과 같은 비교 기호를 씁니다. 식의 값이 0이 아니면 참이고 0이면 거짓입니다.

```bash
if (( num1 < num2 )); then
  echo "num1이 더 작다."
fi
```

`[ "$a" -lt "$b" ]`와 `(( a < b ))`는 둘 다 숫자 비교지만 서로 다른 문법입니다. `[`의 `-lt`를 `(( ))` 안에 넣지 않습니다.

## 반복문

### `for`

목록의 항목을 차례로 처리할 때 사용합니다.

```bash
for name in Linux Bash Shell; do
  echo "$name"
done
```

초기값·조건·증감식을 쓰는 C 스타일도 사용할 수 있습니다.

```bash
for ((i = 1; i <= 3; i++)); do
  echo "$i"
done
```

### `while`

조건 명령의 종료 상태가 성공(0)인 동안 반복합니다. 산술 조건에는 `(( ))`를 쓸 수 있습니다.

```bash
count=1
while (( count <= 3 )); do
  echo "$count"
  ((count += 1))
done
```

## 자주 틀리는 부분

- 변수 대입은 `number=3`처럼 `=` 앞뒤에 공백을 두지 않습니다.
- `$(( ))`는 Bash 자체의 정수 산술 문법이고, `expr`은 명령입니다.
- `expr`에서 연산자와 피연산자는 각각 분리된 인자여야 하며, 곱셈 기호는 이스케이프합니다.
- `read -s`는 입력을 화면에 보이지 않게 할 뿐, 값 자체를 보호하거나 암호화하지 않습니다.
- `read -n 5`는 최대 5자를 읽으며, Enter가 먼저 입력되면 5자보다 적게 읽고 반환할 수 있습니다.
- 여러 줄 here-document 방식은 실제 주석이 아닙니다. 인용하지 않은 종료 표식을 쓰면 본문에서 변수·명령 치환이 일어날 수 있습니다.
- `[`에서는 숫자 비교에 `-eq` 같은 연산자를 쓰고, `(( ))`에서는 `==`, `<`, `>=` 같은 산술 연산자를 씁니다.
