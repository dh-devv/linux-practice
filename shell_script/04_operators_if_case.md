# Bash 연산자 우선순위, `if`/`case` 조건문

이 문서는 산술·논리 연산자의 우선순위, `if`–`elif`–`else` 다중 조건문, `case` 문을 실습 문제와 함께 정리합니다. 기본 문법(`[ ]`, `(( ))`, `read`)은 [03_arithmetic_input_control_flow.md](./03_arithmetic_input_control_flow.md)를 참고합니다. 예제는 `#!/bin/bash` 기준입니다.

## 1. 연산자와 우선순위

연산자에도 **우선순위**가 있습니다. 아래는 높은 것부터 낮은 순서로 정리한 것입니다.

| 우선순위 | 연산자 | 의미 | 종류 |
| :---: | --- | --- | --- |
| 1 | `!` | 논리 부정 (참 ↔ 거짓) | 논리 연산자 |
| 2 | `<<` | 왼쪽 시프트 | 비트 연산자 |
| 2 | `>>` | 오른쪽 시프트 | 비트 연산자 |
| 3 | `&&` | AND (둘 다 참이어야 참) | 논리 연산자 |
| 4 | `||` | OR (하나라도 참이면 참) | 논리 연산자 |

- 우선순위가 헷갈리면 `( )`로 묶어 의도를 분명히 합니다.
- `&&`가 `||`보다 먼저 계산됩니다. `a || b && c`는 `a || (b && c)`와 같습니다.

```bash
echo $(( 1 << 3 ))   # 8  (1을 왼쪽으로 3비트 이동 = 1 × 2³)
echo $(( 16 >> 2 ))  # 4  (16을 오른쪽으로 2비트 이동 = 16 ÷ 2²)

score=75
if (( score >= 60 && score < 80 )); then
  echo "60점 이상 80점 미만"
fi
```

## 2. 문제 1 — 합격/불합격 판별

**문제:** 점수를 입력받아 60점 이상이면 `합격`, 60점 미만이면 `불합격`을 출력한다.

> 문제에 "60점 이하"라고 적었지만 60점은 합격이므로, 정확히는 **60점 미만**이 불합격입니다.

```bash
#!/bin/bash

read -p "점수 입력 >> " score

if (( ${score} >= 60 )); then
  echo "합격"
else
  echo "불합격"
fi
```

### 틀렸던 부분

| 실수 | 올바른 방법 |
| --- | --- |
| 입력받는 방법을 몰랐음 | `read -p "안내 문구" 변수명` |
| 조건식에 `( )` 한 겹만 사용해 오류 발생 | 산술 조건식은 **`(( ))` 이중 괄호** |

- `( )` 한 겹은 서브셸 실행이라 산술 비교 문법이 아닙니다.
- `if (( 조건 )); then`에서 `;`와 `then`을 같은 줄에 쓸 때는 `;`가 필요합니다.

## 3. 다중 조건문: `if` – `elif` – `else`

> 원본 노트의 "중첩 반복문" 제목은 내용상 **다중 조건문**입니다. 반복문이 아니라 조건을 여러 갈래로 나누는 구조입니다.

### 구조

```bash
if (( 조건식1 )); then
  실행문1
elif (( 조건식2 )); then
  실행문2
else
  실행문3
fi
```

- 위에서부터 차례로 검사하고 **처음 참인 분기 하나만** 실행합니다.
- `elif`는 여러 번 쓸 수 있고, `else`는 생략할 수 있습니다.
- 반드시 `fi`로 닫습니다 (`if`를 거꾸로 쓴 것).

### 예시 — `[ ]`와 숫자 비교 연산자

```bash
#!/bin/bash

num1=10
num2=20

if [ ${num1} -lt ${num2} ]; then
  echo "yes"
elif [ ${num1} -eq ${num2} ]; then
  echo "두 수는 같다"
else
  echo "모름"
fi
```

| `[ ]` 연산자 | `(( ))` 연산자 | 의미 |
| --- | --- | --- |
| `-eq` | `==` | 같다 |
| `-ne` | `!=` | 같지 않다 |
| `-lt` | `<` | 작다 |
| `-le` | `<=` | 작거나 같다 |
| `-gt` | `>` | 크다 |
| `-ge` | `>=` | 크거나 같다 |

> 위 예시의 `else`("모름")는 사실상 `num1 > num2`인 경우입니다. 실제로는 "첫 번째 수가 더 크다"처럼 의미를 드러내는 편이 좋습니다.

## 4. 문제 2 — 학점 판별

**문제:** 점수를 입력받아 90 이상 `A`, 80 이상 `B`, 70 이상 `C`, 60 이상 `D`, 그 미만은 `F`를 출력한다.

```bash
#!/bin/bash

read -p "점수 입력: " score

if (( ${score} > 100 )); then
  echo "범위를 벗어남"
elif (( ${score} >= 90 )); then
  echo "A"
elif (( ${score} >= 80 )); then
  echo "B"
elif (( ${score} >= 70 )); then
  echo "C"
elif (( ${score} >= 60 )); then
  echo "D"
else
  echo "F"
fi
```

### 핵심 포인트

- **조건의 순서가 중요합니다.** 높은 점수부터 검사해야 합니다. `>= 60`을 먼저 쓰면 95점도 `D`가 됩니다.
- 범위를 제한하려면 맨 앞에서 `> 100`을 먼저 걸러냅니다.
- 음수 입력(`< 0`)은 현재 코드에서 `F`로 처리됩니다. 필요하면 `(( score < 0 || score > 100 ))`로 함께 처리합니다.

```bash
if (( score < 0 || score > 100 )); then
  echo "범위를 벗어남"
elif ...
```

## 5. `case` 문

하나의 값을 여러 **패턴**과 비교해 분기할 때 사용합니다. 같은 변수를 `==`로 계속 비교하는 `if` 체인보다 읽기 쉽습니다.

### 구조

```bash
case 값 in
  패턴1)
    명령
    ;;
  패턴2)
    명령
    ;;
  *)
    명령      # 위 패턴에 모두 해당하지 않을 때 (default)
    ;;
esac
```

| 요소 | 설명 |
| --- | --- |
| `case 값 in` | 비교할 값을 지정 |
| `패턴)` | 값이 패턴과 일치하면 해당 블록 실행 |
| `;;` | 블록의 끝 (없으면 문법 오류) |
| `*)` | 나머지 모든 경우 (default) |
| `esac` | `case`를 거꾸로 쓴 종료 키워드 |
| <code>패턴1&#124;패턴2)</code> | 여러 패턴을 OR로 묶음 |

### 실습 1 — 과목 분기

```bash
#!/bin/bash

# case 문 실습하기

subject="Linux"

case ${subject} in
  "c")
    echo "C 수업"
    ;;
  "JAVA")
    echo "JAVA 수업"
    ;;
  "Linux")
    echo "Linux 수업"      # 출력: Linux 수업
    ;;
  "Python")
    echo "Python 수업"
    ;;
  *)
    echo "해당 없음"
    ;;
esac
```

### 실습 2 — 여러 패턴 묶기 (`|`)

```bash
#!/bin/bash

country=korea

case ${country} in
  "korea"|"china")
    echo "Asia"            # 출력: Asia
    ;;
  "USA"|"Canada"|"mexico")
    echo "America"
    ;;
  *)
    echo "Another world"
    ;;
esac
```

> 원본 노트의 `Ameria`는 오타여서 `America`로 고쳤습니다. 또한 `case`의 문자열 비교는 **대소문자를 구분**합니다. `"mexico"`는 `"Mexico"`와 일치하지 않습니다.

## 6. 문제 3 — 과일 가격 (`case` 사용)

**문제:** 과일 이름을 입력받아 사과 1000원, 바나나 1500원, 포도 3000원을 출력하고, 그 외에는 `판매하는 상품이 아닙니다.`를 출력한다.

```bash
#!/bin/bash

read -p "과일 이름: " fruit

case ${fruit} in
  "사과")
    echo "1000원"
    ;;
  "바나나")
    echo "1500원"
    ;;
  "포도")
    echo "3000원"
    ;;
  *)
    echo "판매하는 상품이 아닙니다."
    ;;
esac
```

## 7. `if` vs `case` 선택 기준

| 상황 | 권장 |
| --- | --- |
| 숫자 **범위** 비교 (90 이상, 80 이상 …) | `if` – `elif` |
| 하나의 값이 **정확히 일치**하는지 여러 개 비교 | `case` |
| 여러 조건을 `&&`, `||`로 조합 | `if` |

학점 문제는 범위 비교라 `if`, 과일 문제는 값 일치 비교라 `case`가 어울립니다.

## 자주 틀리는 부분

- 산술 조건은 `( )`가 아니라 **`(( ))`** 입니다.
- `[ ]` 안팎에는 공백이 필요하고, 숫자 비교는 `-lt` 등을 씁니다.
- `if`는 `fi`, `case`는 `esac`로 닫습니다.
- `case`의 각 블록은 `;;`로 끝냅니다.
- 범위 비교의 `elif`는 **큰 값부터** 순서대로 작성합니다.
- 입력 처리는 `read -p "문구" 변수`를 사용합니다.
