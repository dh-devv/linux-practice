# Bash 반복문: `for`, `while`

이 문서는 `for`(C 스타일·배열 순회)와 `while` 반복문의 구조와 실행 순서, 실습 예제를 정리합니다. 예제는 `#!/bin/bash` 기준입니다.

## 1. C 스타일 `for`

### 실행 순서

```text
초기식 → 조건식 검사 ─ 거짓 → 반복 종료
              │
              참
              ↓
        실행문 실행 → 증감식 실행 → 조건식 검사로 돌아감
```

1. **초기식**을 실행한다 (최초 1회만).
2. **조건식**을 검사한다.
3. 조건식의 결과로 `for`문 실행 여부를 판단한다. 거짓이면 종료한다.
4. 참이면 블록 안의 **실행문**을 실행한다.
5. 블록의 실행이 끝나면 **증감식**을 실행한다.
6. 증감식 뒤에 **2번으로 돌아간다.**

### 구조

```bash
for (( 초기식; 조건식; 증감식 )); do
  실행문
done
```

| 부분 | 예시 | 설명 |
| --- | --- | --- |
| 초기식 | `i=1` | 시작 값 (한 번만 실행) |
| 조건식 | `i<=10` | 참인 동안 반복 |
| 증감식 | `i++` | 한 바퀴 끝날 때마다 실행 |

### 실습

```bash
#!/bin/bash

for (( i=1; i<=4; i++ )); do
  echo "Hello World!"
done
```

출력 (4번 반복):

```text
Hello World!
Hello World!
Hello World!
Hello World!
```

## 2. 배열 순회 `for ... in`

배열의 요소를 하나씩 꺼내 변수에 담아 반복합니다.

```bash
#!/bin/bash

array=(10 20 30 40 50)

for i in "${array[@]}"; do
  echo "${i}"
done
```

출력:

```text
10
20
30
40
50
```

### 틀렸던 부분

| 실수 | 올바른 방법 |
| --- | --- |
| `array[@]`를 `${ }`로 감싸지 않음 | **`"${array[@]}"`** 처럼 `${ }`로 감싸고 큰따옴표 사용 |
| `do`를 `for` 줄 끝에 `;` 없이 붙여 씀 | `do`를 **다음 줄**에 쓰거나, `; do`로 같은 줄에 씀 |

```bash
# 방법 1: do를 다음 줄에
for i in "${array[@]}"
do
  echo "${i}"
done

# 방법 2: 같은 줄에서는 ; 필수
for i in "${array[@]}"; do
  echo "${i}"
done
```

### 배열 참조 정리

| 표현 | 의미 |
| --- | --- |
| `${array[0]}` | 첫 번째 요소 |
| `"${array[@]}"` | 모든 요소 (각 요소를 별개의 단어로 유지) |
| `${#array[@]}` | 요소의 개수 |

> `"${array[@]}"`는 공백이 포함된 요소도 하나로 유지하므로 순회에 안전합니다.

## 3. `while` 문

조건이 **참인 동안** 반복합니다. `for`와 달리 초기식·증감식 자리가 없으므로 **직접 작성**해야 합니다. 증감식을 빠뜨리면 무한 루프가 됩니다.

### 구조

```bash
초기식
while (( 조건식 )); do
  실행문
  증감식
done
```

### 실습 — 1부터 10까지 출력

```bash
#!/bin/bash

i=1                          # 초기식

while (( ${i} <= 10 )); do   # 조건식
  echo "${i}"
  i=$(( ${i} + 1 ))          # 증감식
done
```

- 증감식은 `((i++))` 또는 `(( i += 1 ))`로 줄여 쓸 수 있습니다.
- `i=$(( i + 1 ))`는 계산 결과를 변수에 **대입**하는 방식이고, `(( i++ ))`는 변수를 **직접 증가**시키는 방식입니다.

## 4. `for`와 `while` 비교

| 구분 | `for` | `while` |
| --- | --- | --- |
| 적합한 상황 | 횟수나 대상이 정해진 반복 | 조건이 만족되는 동안 반복 |
| 초기식·증감식 | 문법 안에 포함 | 직접 작성 |
| 무한 루프 위험 | 낮음 | 증감식 누락 시 발생 |

같은 동작을 두 방식으로 쓴 예:

```bash
for (( i=1; i<=10; i++ )); do echo "${i}"; done

i=1
while (( i <= 10 )); do echo "${i}"; (( i++ )); done
```

## 자주 틀리는 부분

- C 스타일 `for`는 `(( ))` 이중 괄호를 사용합니다.
- 배열 순회는 `"${array[@]}"`로 씁니다.
- `do`를 같은 줄에 쓰면 앞에 `;`가 필요합니다.
- `while`은 초기식과 증감식을 직접 작성하며, 증감식을 빠뜨리면 무한 루프에 빠집니다.
- 반복문은 `done`으로 닫습니다.
