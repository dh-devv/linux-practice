# Linux Day 10 - chmod를 이용한 접근 권한 변경

## 1. chmod란?

`chmod`는 파일이나 디렉터리의 접근 권한을 변경하는 명령어입니다.

`chmod`는 다음 두 가지 방법으로 사용할 수 있습니다.

1. 8진수 숫자를 이용하는 방법
2. 기호를 이용하는 방법

## 2. 8진수를 이용한 권한 변경

Linux에서는 각 권한에 숫자를 부여합니다.

| 권한 | 숫자 |
| --- | --- |
| `r` | 4 |
| `w` | 2 |
| `x` | 1 |

권한이 없으면 숫자에 포함하지 않습니다.

예를 들어 다음과 같이 계산합니다.

```text
rwx = 4 + 2 + 1 = 7
rw- = 4 + 2 + 0 = 6
r-x = 4 + 0 + 1 = 5
r-- = 4 + 0 + 0 = 4
--- = 0
```

권한은 소유자, 그룹, 기타 사용자 순서로 세 자리 숫자를 사용합니다.

```text
소유자 | 그룹 | 기타 사용자
  7   |  5  |    5
```

따라서 `rwxr-xr-x`는 `755`로 표현할 수 있습니다.

## 3. 자주 사용하는 권한 표현

| 문자 방식 | 숫자 방식 | 의미 |
| --- | --- | --- |
| `rwxrwxrwx` | `777` | 모든 사용자가 읽기, 쓰기, 실행 가능 |
| `rwxr-xr-x` | `755` | 소유자는 모든 권한, 그룹과 기타 사용자는 읽기와 실행 가능 |
| `rw-rw-r--` | `664` | 소유자와 그룹은 읽기와 쓰기 가능, 기타 사용자는 읽기만 가능 |
| `rw-r--r--` | `644` | 소유자는 읽기와 쓰기 가능, 나머지는 읽기만 가능 |
| `rw-r-----` | `640` | 소유자는 읽기와 쓰기 가능, 그룹은 읽기 가능 |
| `rwx------` | `700` | 소유자만 모든 권한을 가짐 |
| `rw-------` | `600` | 소유자만 읽기와 쓰기 가능 |

## 4. chmod 실습

### 모든 사용자에게 모든 권한 부여

```bash
chmod 777 /test/copy_test.txt
```

`copy_test.txt` 파일에 대해 소유자, 그룹, 기타 사용자가 모두 읽기, 쓰기, 실행을 할 수 있도록 변경합니다.

다만 `777` 권한은 모든 사용자에게 쓰기 권한을 주기 때문에 보안상 주의해서 사용해야 합니다.

### 소유자는 읽기와 쓰기, 나머지는 읽기만 가능

```bash
chmod 644 /test/copy_test.txt
```

다음과 같이 변경됩니다.

- 소유자: 읽기, 쓰기
- 그룹: 읽기
- 기타 사용자: 읽기

### 소유자만 읽기와 쓰기 가능

```bash
chmod 600 /test/copy_test.txt
```

다음과 같이 변경됩니다.

- 소유자: 읽기, 쓰기
- 그룹: 권한 없음
- 기타 사용자: 권한 없음

### 소유자는 모든 권한, 그룹과 기타 사용자는 읽기와 실행 가능

```bash
chmod 755 /test/rename.txt
```

다음과 같이 변경됩니다.

- 소유자: 읽기, 쓰기, 실행
- 그룹: 읽기, 실행
- 기타 사용자: 읽기, 실행

## 5. 기호를 이용한 chmod

기호 방식은 다음 세 가지 요소를 조합합니다.

```text
대상 + 연산자 + 권한
```

### 대상

| 기호 | 대상 |
| --- | --- |
| `u` | 소유자(user) |
| `g` | 그룹(group) |
| `o` | 기타 사용자(other) |
| `a` | 모든 사용자(all) |

### 연산자

| 기호 | 의미 |
| --- | --- |
| `+` | 권한 추가 |
| `-` | 권한 제거 |
| `=` | 권한을 지정한 값으로 변경 |

### 권한

| 기호 | 의미 |
| --- | --- |
| `r` | 읽기 |
| `w` | 쓰기 |
| `x` | 실행 |

## 6. 기호 방식 실습

### 소유자에게 실행 권한 추가

```bash
chmod u+x test.txt
```

`test.txt` 파일의 소유자에게 실행 권한을 추가합니다.

### 기타 사용자에게 읽기 권한 제거

```bash
chmod o-r test.txt
```

`test.txt` 파일에서 기타 사용자의 읽기 권한을 제거합니다.

### 모든 사용자에게 읽기 권한만 부여

```bash
chmod a=r test.txt
```

소유자, 그룹, 기타 사용자의 권한을 모두 읽기 권한만 갖도록 변경합니다.

### 기타 사용자의 실행 권한 제거

```bash
chmod o-x /test/copy_test.txt
```

`copy_test.txt` 파일에서 기타 사용자의 실행 권한을 제거합니다.

## 7. 권한 확인

권한을 변경한 뒤에는 `ls -l` 명령어로 결과를 확인합니다.

```bash
ls -l /test/copy_test.txt
```

파일의 권한만 확인하고 싶다면 다음과 같이 사용할 수 있습니다.

```bash
stat /test/copy_test.txt
```

## 핵심 정리

- `chmod`는 파일과 디렉터리의 접근 권한을 변경합니다.
- `r`, `w`, `x`는 각각 `4`, `2`, `1`로 계산합니다.
- 숫자 방식은 소유자, 그룹, 기타 사용자 순서로 작성합니다.
- `755`는 실행 파일이나 디렉터리에서 자주 사용됩니다.
- `644`는 일반적인 문서 파일에 자주 사용됩니다.
- `777`은 모든 사용자에게 쓰기 권한을 주기 때문에 주의해야 합니다.
- 기호 방식에서는 대상, 연산자, 권한을 조합합니다.
