# Linux Day 07 - 파일 권한의 기본 개념

## 1. 파일 권한 확인하기

Linux에서는 `ls -l` 명령어를 사용하면 파일과 디렉터리의 상세 정보를 확인할 수 있습니다.

```bash
ls -l
```

실행 결과 예시는 다음과 같습니다.

```text
drwxr-xr-x 4 root root 4096 Aug 26 21:42 test
```

각 항목의 의미는 다음과 같습니다.

| 항목 | 의미 |
| --- | --- |
| `d` | 파일의 종류 |
| `rwxr-xr-x` | 파일 또는 디렉터리의 접근 권한 |
| `4` | 하드 링크 수 |
| 첫 번째 `root` | 파일 소유자 |
| 두 번째 `root` | 파일이 속한 그룹 |
| `4096` | 파일 크기 |
| `Aug 26 21:42` | 마지막 수정 날짜와 시간 |
| `test` | 파일 또는 디렉터리 이름 |

## 2. 파일 종류

권한 정보의 가장 첫 번째 문자는 파일의 종류를 나타냅니다.

| 기호 | 파일 종류 |
| --- | --- |
| `-` | 일반 파일 |
| `d` | 디렉터리 |
| `c` | 문자 장치 파일 |
| `b` | 블록 장치 파일 |
| `s` | 소켓 파일 |
| `l` | 심볼릭 링크 |
| `p` | FIFO 파일 |

예를 들어 다음과 같은 권한 정보가 있을 때,

```text
drwxr-xr-x
```

첫 번째 문자 `d`는 해당 항목이 디렉터리라는 뜻입니다.

다음과 같이 첫 번째 문자가 `-`이면 일반 파일입니다.

```text
-rw-r--r--
```

## 3. 접근 권한의 종류

Linux의 기본 접근 권한은 읽기, 쓰기, 실행으로 나뉩니다.

| 기호 | 의미 | 일반 파일에서의 의미 |
| --- | --- | --- |
| `r` | 읽기 | 파일 내용을 읽을 수 있음 |
| `w` | 쓰기 | 파일 내용을 수정할 수 있음 |
| `x` | 실행 | 파일을 실행할 수 있음 |

디렉터리에서는 권한의 의미가 조금 다릅니다.

| 권한 | 디렉터리에서의 의미 |
| --- | --- |
| `r` | 디렉터리 내부 목록을 확인할 수 있음 |
| `w` | 디렉터리 안에 파일을 생성하거나 삭제할 수 있음 |
| `x` | 디렉터리에 접근하거나 내부 항목에 접근할 수 있음 |

## 4. 권한의 적용 대상

권한은 세 개의 대상에게 각각 적용됩니다.

```text
rwx r-x r-x
```

왼쪽부터 세 글자씩 나누어 확인합니다.

```text
rwx | r-x | r-x
```

| 위치 | 대상 |
| --- | --- |
| 첫 번째 세 글자 | 소유자(owner) |
| 두 번째 세 글자 | 그룹(group) |
| 세 번째 세 글자 | 기타 사용자(other) |

따라서 다음 권한은

```text
rwxr-xr-x
```

다음과 같이 해석할 수 있습니다.

- 소유자: 읽기, 쓰기, 실행 가능
- 그룹: 읽기, 실행 가능
- 기타 사용자: 읽기, 실행 가능

## 5. 권한 해석 연습

### `rwxr-xr-x`

- 소유자: 읽기, 쓰기, 실행
- 그룹: 읽기, 실행
- 기타 사용자: 읽기, 실행

### `rw-rw-r--`

- 소유자: 읽기, 쓰기
- 그룹: 읽기, 쓰기
- 기타 사용자: 읽기

### `rw-r--r--`

- 소유자: 읽기, 쓰기
- 그룹: 읽기
- 기타 사용자: 읽기

### `rw-r-----`

- 소유자: 읽기, 쓰기
- 그룹: 읽기
- 기타 사용자: 권한 없음

### `rwx------`

- 소유자: 읽기, 쓰기, 실행
- 그룹: 권한 없음
- 기타 사용자: 권한 없음

## 6. 파일 소유자와 그룹

### 파일 소유자

파일 소유자는 해당 파일을 소유하는 사용자를 말합니다.

일반적으로 파일을 만든 사용자가 파일의 소유자가 됩니다.

### 파일 그룹

파일 그룹은 해당 파일이 속한 그룹을 의미합니다.

시스템 관리자는 비슷한 업무를 수행하는 사용자들을 하나의 그룹으로 묶어 권한을 관리할 수 있습니다.

예를 들어 다음 결과를 보면,

```text
-rw-r--r-- 1 dh developers 120 Aug 26 21:42 test.txt
```

- `dh`: 파일 소유자
- `developers`: 파일이 속한 그룹

## 핵심 정리

- `r`은 읽기 권한입니다.
- `w`는 쓰기 권한입니다.
- `x`는 실행 권한입니다.
- 권한은 소유자, 그룹, 기타 사용자 순서로 표시됩니다.
- 권한 문자열의 첫 번째 문자는 파일의 종류를 나타냅니다.
- `ls -l` 명령어로 파일의 종류, 권한, 소유자, 그룹 등을 확인할 수 있습니다.
