# 리눅스의 역사

## UNIX의 탄생과 발전
- **1960년대 후반**: 여러 기관이 참여해 시분할 운영체제 **Multics**를 개발하기 시작했다.

- **1969년경**: 벨 연구소의 **켄 톰프슨(Ken Thompson)** 등이 Multics에서 얻은 아이디어를 바탕으로 UNIX를 개발하기 시작했다. “Multics를 단순화해 UNIX를 만들었다”라고만 외우기보다, Multics가 UNIX 개발에 영향을 주었다고 이해한다.

- **1972년**: **데니스 리치(Dennis Ritchie)**가 C 언어를 개발했다.

- **1973년경**: UNIX 커널의 대부분을 C 언어로 다시 작성했다. 어셈블리어에만 의존하지 않게 되어 다른 하드웨어로 이식하기 쉬워졌다.

- 이후 UNIX는 여러 계열로 발전했으며, 대표적으로 **BSD 계열**과 **System V 계열**이 있다.

### 알아둘 용어
- **시분할 시스템(time-sharing system)**: CPU 시간을 여러 사용자나 작업에 짧은 단위로 나누어 제공하는 방식이다. 여러 사용자가 동시에 사용하는 것처럼 느끼게 한다.

- **이식성(portability)**: 프로그램을 다른 하드웨어나 운영체제 환경으로 옮겨 실행하기 쉬운 정도다. UNIX를 C로 다시 작성한 것은 이식성을 높이는 데 중요한 역할을 했다.

- **BSD(Berkeley Software Distribution)**: 캘리포니아대학교 버클리에서 발전시킨 UNIX 계열이다.

- **System V**: AT&T에서 발전시킨 대표적인 UNIX 계열이다.

## 자유 소프트웨어 운동과 GNU
- **1983년**: **리처드 스톨만(Richard Stallman)**이 GNU 프로젝트를 시작했다. 목표는 유닉스와 호환되는 자유 소프트웨어 운영체제 및 도구를 만드는 것이었다.

- **GNU**는 **“GNU's Not Unix”**의 재귀적 약어다. 유닉스와 호환되도록 만들되 유닉스 자체에 종속되지 않는다는 취지를 나타낸다.

- **1985년**: 스톨만이 자유 소프트웨어 운동을 지원하기 위해 **FSF(Free Software Foundation, 자유 소프트웨어 재단)**를 설립했다.

- GNU 프로젝트는 컴파일러, 셸, 편집기 등 운영체제에 필요한 여러 도구를 개발했다.

- GNU가 개발한 도구와 리눅스 커널이 결합하면서 완전한 운영체제 환경을 구성할 수 있었다. 이를 **GNU/Linux**라고 부르기도 한다.

### 자유 소프트웨어와 오픈 소스
- **자유 소프트웨어**에서 ‘자유’는 단순히 무료라는 뜻이 아니라, 프로그램을 실행·연구·수정·재배포할 자유를 뜻한다.

- 공개된 소프트웨어라도 사용·수정·재배포 조건은 라이선스에 따른다.

## MINIX와 리눅스 커널의 탄생
- **MINIX**는 앤드루 타넨바움(Andrew S. Tanenbaum)이 교육과 연구를 위해 만든 유닉스 계열 운영체제다. GNU 프로젝트와는 별개의 운영체제이며, 리누스 토르발스가 리눅스 커널을 개발하던 시기에 사용한 환경 중 하나다.

- **1991년**: 핀란드의 **리누스 토르발스(Linus Torvalds)**가 개인용 컴퓨터용 운영체제 커널 개발을 시작했다.

- **1991년 8월**: 토르발스가 유즈넷에 새 운영체제 커널 개발 사실을 알렸다.

- **1991년 9월**: 초기 리눅스 커널 **0.01**을 공개했다.

- **1992년**: 리눅스 커널에 **GPL**을 적용했다. 자유롭게 사용·수정·재배포할 수 있도록 하되, GPL의 조건을 따르도록 했다.

- **1994년 3월**: 리눅스 커널 **1.0**을 발표했다.

- **1996년 6월**: 리눅스 커널 **2.0**을 발표했다.

### 알아둘 용어
- **커널(kernel)**: 운영체제의 핵심 부분으로, CPU·메모리·장치와 실행 중인 프로그램 사이의 자원을 관리한다. 리눅스는 엄밀히 말하면 커널의 이름이며, 일상적으로는 이를 포함한 운영체제 전체를 가리키기도 한다.

- **GPL(GNU General Public License)**: 소프트웨어를 사용·수정·배포할 수 있도록 허용하는 자유 소프트웨어 라이선스다. 배포할 때는 라이선스의 조건을 지켜야 하며, GPL 적용이 저작권이 없다는 뜻은 아니다.

- **리눅스 배포판(distribution)**: 리눅스 커널에 시스템 도구, 라이브러리, 설치·패키지 관리 도구와 응용 프로그램 등을 더해 사용하기 편한 운영체제 형태로 묶은 것이다.

## 주요 연표 한눈에 보기

| 시기 | 사건 | 기억할 이름·키워드 |
|---|---|---|
| 1960년대 후반 | Multics 개발 시작 | 시분할 운영체제 |
| 1969년경 | UNIX 개발 시작 | 켄 톰프슨, 벨 연구소 |
| 1972년 | C 언어 개발 | 데니스 리치 |
| 1973년경 | UNIX 커널을 C 언어로 재작성 | 이식성 향상 |
| 1983년 | GNU 프로젝트 시작 | 리처드 스톨만 |
| 1985년 | FSF 설립 | 자유 소프트웨어 재단 |
| 1987년 | MINIX 등장 | 앤드루 타넨바움, 교육용 유닉스 계열 OS |
| 1991년 | 리눅스 커널 개발·초기 버전 공개 | 리누스 토르발스, 0.01 |
| 1992년 | 리눅스 커널에 GPL 적용 | 자유 소프트웨어 라이선스 |
| 1994년 3월 | 리눅스 커널 1.0 발표 | 1.0 |
| 1996년 6월 | 리눅스 커널 2.0 발표 | 2.0 |

> 연도와 버전 날짜는 시험 교재의 기준에 따라 표기 방식에 차이가 있을 수 있다. 핵심 순서는 **GNU 시작(1983) → FSF 설립(1985) → 리눅스 0.01 공개(1991) → GPL 적용(1992) → 커널 1.0(1994) → 커널 2.0(1996)**이다.

## 시험 대비 정리

### 기존 메모에서 바로잡을 점
- GNU 프로젝트는 **1980년대**라는 정도보다 **1983년 시작**으로 기억하는 것이 좋다.

- FSF는 GNU 프로젝트와 동시에 설립된 것이 아니라 **1985년** 리처드 스톨만이 설립했다.

- MINIX는 GNU가 개발한 운영체제가 아니다. **앤드루 타넨바움이 만든 교육용 유닉스 계열 운영체제**다.

- 초기 리눅스 공개 버전은 일반적으로 **0.01**로 표기한다. “0.0.1”과 혼동하지 않는다.

- 리눅스 커널은 **1992년 GPL을 적용**, **1994년 1.0**, **1996년 2.0** 순서로 발전했다.

- C 언어 개발은 **1972년**, UNIX 커널의 C 언어 재작성은 **1973년경**으로 구분한다.

### 우선 암기할 항목
1. UNIX와 C 언어: **켄 톰프슨—UNIX 개발**, **데니스 리치—C 언어 개발**, UNIX 커널을 C로 재작성해 이식성을 높임.

2. GNU와 FSF: **리처드 스톨만—GNU 프로젝트(1983)와 FSF(1985)**.

3. MINIX: **앤드루 타넨바움이 개발한 교육용 유닉스 계열 OS**.

4. 리눅스: **리누스 토르발스가 1991년 개발·공개**, 초기 버전은 **0.01**.

5. 주요 버전 순서: **1992 GPL 적용 → 1994 커널 1.0 → 1996 커널 2.0**.

6. UNIX의 대표 계열: **BSD와 System V**.

7. GNU 도구와 리눅스 커널의 결합으로 GNU/Linux 시스템을 구성할 수 있음.

### 스스로 확인하기
- UNIX 개발에 영향을 준 시분할 운영체제는 무엇인가?

- UNIX 커널을 C 언어로 다시 작성한 이유는 무엇인가?

- GNU 프로젝트와 FSF를 시작·설립한 사람과 연도는 무엇인가?

- MINIX를 개발한 사람은 누구이며, GNU와 어떤 관계인가?

- 리눅스 커널의 개발자, 초기 공개 연도·버전, GPL 적용 연도를 말할 수 있는가?

- 리눅스 커널 1.0과 2.0은 각각 몇 년에 발표되었는가?

- BSD와 System V는 무엇의 대표적인 계열인가?

답을 가리고 연표를 순서대로 설명해 보세요. 인물 이름만 따로 외우기보다 **인물—사건—연도**를 한 묶음으로 기억하고, 기출 문제에서 표현이 달라져도 구분할 수 있는지 확인하는 것이 효과적입니다.
