# 부트 매니저와 리눅스 부팅

> 이 문서는 [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 리눅스 부트 내용을 정리한 것입니다. 웹 페이지의 부팅 과정과 GRUB 설정 예시는 **구형 BIOS·SysV init·GRUB Legacy 환경**을 기준으로 하므로, 모든 리눅스 환경에 그대로 적용되는 것은 아닙니다.

## 1. 부트 매니저와 부트 로더

컴퓨터를 켜면 운영체제를 사용할 수 있도록 부팅 과정이 진행됩니다. 하나의 컴퓨터에 여러 운영체제가 설치되어 있다면 **부트 매니저**에서 사용할 운영체제를 선택할 수 있습니다. 이렇게 여러 운영체제 중 하나를 골라 시작하는 것을 **멀티 부팅**이라고 합니다.

**부트 로더(Boot Loader)**는 운영체제보다 먼저 실행되어 운영체제의 커널을 메모리에 적재하고 부팅을 이어 가는 프로그램입니다.

| 구분 | 역할 |
| --- | --- |
| 부트 매니저 | 부팅할 운영체제나 메뉴 항목을 선택하도록 함 |
| 부트 로더 | 선택한 운영체제의 커널을 불러와 부팅을 진행함 |

### 웹 자료에서 소개한 부트 로더

| 이름 | 설명 |
| --- | --- |
| LILO | 웹 자료에서 소개하는 리눅스 부트 로더 |
| GRUB | 메뉴와 대화형 설정을 지원하며, 커널 경로와 파일 이름을 지정해 부팅할 수 있음 |

## 2. 리눅스 부팅 과정

웹 자료의 전통적인 부팅 흐름은 다음과 같습니다.

```text
BIOS 실행과 POST
    ↓
부트 로더 실행 → 커널 로딩
    ↓
장치 드라이버 초기화 → init 프로세스 실행
    ↓
런 레벨 결정 → 초기화·런 레벨별 스크립트 실행
    ↓
선택된 환경으로 부팅
```

1. **BIOS와 POST**: 하드웨어를 검사하고 부트 로더를 불러옵니다.
2. **부트 로더**: 커널을 로딩하여 부팅을 이어 갑니다. 웹 자료에는 LILO와 GRUB가 예로 제시되어 있습니다.
3. **초기화**: 장치 드라이버를 초기화하고 `init` 프로세스를 실행합니다.
4. **런 레벨 결정**: 웹 자료의 예에서는 `init`이 `/etc/inittab`을 참조합니다.
5. **스크립트 실행**: 시스템 초기화 스크립트와 런 레벨에 해당하는 스크립트를 실행합니다.
6. **환경 시작**: 예를 들어 웹 자료의 런 레벨 5는 X 윈도 환경으로 부팅합니다.

> 위 흐름은 웹 자료에 나온 전통적인 방식의 학습용 정리입니다. 실제 시스템의 부팅 구성과 파일 경로는 환경에 따라 다를 수 있습니다.

## 3. GRUB 설정 예시 읽기

웹 자료는 `/boot/grub/grub.conf`에 있는 **GRUB Legacy** 설정을 예시로 설명합니다. 아래는 각 항목의 역할을 이해하기 위한 발췌입니다.

```text
default=0
timeout=5
splashimage=(hd0,0)/grub/splash.xpm.gz
hiddenmenu
title CentOS (2.6.18-308.el5)
    root (hd0,0)
    kernel /vmlinuz-2.6.18-308.el5 ro root=LABEL=/
    initrd /initrd-2.6.18-308.el5.img
```

| 항목 | 의미 |
| --- | --- |
| `default=0` | 메뉴를 선택하지 않을 때 사용할 기본 메뉴. 메뉴 번호는 0부터 시작 |
| `timeout=5` | 기본 메뉴로 부팅하기 전 5초 동안 선택을 기다림 |
| `splashimage` | 부팅 화면의 배경 이미지 지정 |
| `password` | 웹 자료에서 GRUB 메뉴 접근에 사용하는 암호 설정 항목으로 소개 |
| `title` | 부팅 메뉴에 표시되는 제목 |
| `root (hd0,0)` | 이 예시에서 첫 번째 디스크의 첫 번째 파티션을 지정 |
| `kernel` | 불러올 커널 이미지의 경로와 부팅에 사용할 설정 지정 |
| `initrd` | 부팅에 사용할 초기 이미지의 경로 지정 |

예를 들어 `timeout=5`와 `default=0`이 함께 있으면 메뉴 선택을 5초 동안 기다린 후 첫 번째 메뉴를 기본으로 선택합니다.

> 웹 자료는 특정 구형 SCSI 부팅 예에서 `initrd`의 필요성을 설명합니다. 이를 모든 시스템에 대한 조건으로 일반화하지 마세요. 설정 파일을 수정하기 전에 사용하는 환경의 부트 로더와 설정 방식을 확인해야 합니다.

### GRUB Legacy 편집 화면의 키

웹 자료의 GRUB 0.98 예시에서 초기 화면의 `c`는 명령행 화면, `e`는 메뉴 편집 화면으로 들어갑니다.

| 키 | 웹 자료의 기능 |
| --- | --- |
| `↑`, `↓` | 항목 이동 |
| `a` | 커널 매개변수 추가 |
| `b` | 선택한 부팅 항목으로 부팅 |
| `c` | 대화식 명령행 열기 |
| `d` | 선택한 행 삭제 |
| `e` | 선택한 항목 편집 |
| `o` / `O` | 선택한 행 뒤 / 앞에 새 행 삽입 |
| `Esc` | 이전 메뉴로 이동 |

> 이 표는 웹 자료의 **GRUB Legacy 편집 화면**에 대한 설명입니다. 실제 설정을 바꾸는 실습이 아니라 화면과 키의 역할을 이해하는 용도로 살펴보세요.

## 4. 런 레벨(Run Level)

런 레벨은 웹 자료의 전통적인 `init` 방식에서 시스템이 어떤 운영 모드로 시작할지 구분하는 값입니다. 웹 자료의 순서에 맞춰 0부터 6까지 정리했습니다.

| 런 레벨 | 웹 자료의 운영 모드 |
| --- | --- |
| 0 | 시스템 종료 |
| 1 | 단일 사용자 모드, CLI |
| 2 | 네트워크를 사용하지 않는 다중 사용자 모드, CLI |
| 3 | 콘솔 로그인 다중 사용자 모드, CLI |
| 4 | 사용하지 않음 |
| 5 | 디스플레이 관리자를 사용하는 다중 사용자 모드, GUI·X 윈도 |
| 6 | 시스템 재시작 |

### 관련 파일과 확인

| 경로 | 웹 자료에서 설명하는 역할 |
| --- | --- |
| `/etc/inittab` | `init`이 참조하는 런 레벨 설정 |
| `/etc/rc.d/init.d` | 서비스를 시작·종료·재시작하는 스크립트 |
| `/etc/rc.d/rc.local` | 부팅 시 자동 실행할 명령을 추가하는 스크립트 |
| `/etc/rc.d/rc0.d` ~ `/etc/rc.d/rc6.d` | 각 런 레벨에 맞는 서비스 실행 관련 디렉터리 |

웹 자료의 `runlevel` 출력 예시를 읽어 봅니다.

```text
$ runlevel
N 3
```

이 예시는 현재 런 레벨이 `3`인 경우입니다. 위 파일과 명령 역시 웹 자료의 전통적인 `init` 환경을 기준으로 이해하세요.

## 5. 복습

- **부트 매니저**는 부팅할 운영체제를 선택할 수 있게 합니다.
- **부트 로더**는 커널을 불러와 부팅을 진행합니다.
- GRUB Legacy 예시에서 `default`는 기본 메뉴, `timeout`은 대기 시간입니다.
- 웹 자료의 런 레벨에서 `0`은 종료, `3`은 콘솔 다중 사용자, `5`는 GUI, `6`은 재시작입니다.
