# 사용자 생성 및 계정 관리

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 사용자·그룹 관리 내용을 주제별로 정리했습니다. 계정이나 그룹을 변경하는 명령은 시스템에 영향을 주므로, 실습 전용 환경에서 관리자 권한과 대상 이름을 확인하세요. 아래의 `test`와 `test2`는 웹 자료의 예시 이름입니다.

## 1. 사용자 계정과 관련 파일

사용자 계정은 사용자를 식별하고 로그인 환경을 관리하는 데 사용합니다. **UID**는 사용자 식별 번호, **GID**는 그룹 식별 번호입니다.

| 파일·디렉터리 | 역할 |
| --- | --- |
| `/etc/default/useradd` | 계정 생성에 사용하는 기본 홈 위치, 셸 등의 설정 |
| `/etc/login.defs` | UID 범위, 비밀번호 사용 기간 등 계정 관련 기본 설정 |
| `/etc/skel` | 새 홈 디렉터리를 만들 때 복사할 기본 파일이 있는 곳 |
| `/etc/passwd` | 사용자 이름, UID, GID, 홈 디렉터리, 로그인 셸 등 계정 정보 |
| `/etc/shadow` | 비밀번호 관련 정보와 계정·비밀번호 만료 정보 |
| `/etc/group` | 그룹 이름, GID, 구성원 등 그룹 정보 |

### `/etc/passwd` 읽기

각 항목은 콜론(`:`)으로 구분됩니다.

```text
test:x:1000:1000:linux:/home/test:/bin/bash
```

| 순서 | 예시 | 의미 |
| --- | --- | --- |
| 1 | `test` | 계정 이름 |
| 2 | `x` | 비밀번호 관련 표시 |
| 3 | `1000` | UID |
| 4 | `1000` | 기본 그룹의 GID |
| 5 | `linux` | 계정 설명 |
| 6 | `/home/test` | 홈 디렉터리 |
| 7 | `/bin/bash` | 로그인 셸 |

### `/etc/shadow` 읽기

웹 자료는 `/etc/shadow`가 콜론으로 구분된 9개 필드라고 설명합니다.

```text
계정명:비밀번호 정보:최종 변경일:최소 일수:최대 일수:경고 일수:비활성 기간:계정 만료일:예약
```

비밀번호 자체를 화면에 적어 두는 파일로 생각하지 말고, 비밀번호와 만료 정책을 관리하는 민감한 정보로 다루세요.

### 계정 생성 기본값

`/etc/default/useradd`에는 `HOME`, `SHELL`, `SKEL`과 같은 항목이 있습니다. 예를 들어 `SKEL=/etc/skel`은 새 홈 디렉터리에 복사할 기본 파일의 위치를 가리킵니다.

`/etc/login.defs`의 예시 항목은 다음과 같습니다.

| 설정 | 의미 |
| --- | --- |
| `PASS_MAX_DAYS` | 비밀번호의 최대 사용 기간 |
| `PASS_MIN_DAYS` | 비밀번호를 다시 변경하기까지의 최소 일수 |
| `PASS_WARN_AGE` | 비밀번호 만료 전 경고 기간 |
| `UID_MIN`, `UID_MAX` | 사용자에게 할당하는 UID 범위 |
| `CREATE_HOME` | 홈 디렉터리 생성 여부 |
| `UMASK` | 홈 디렉터리 생성에 적용할 마스크 |

웹 자료의 `/etc/skel` 예시에는 `.bash_logout`, `.bash_profile`, `.bashrc`가 있습니다.

## 2. 사용자 생성: `useradd`

`useradd`는 사용자 계정을 생성합니다.

```bash
useradd [옵션] 계정명
```

| 옵션 | 의미 |
| --- | --- |
| `-c` | 계정 설명 지정 |
| `-d` | 홈 디렉터리 지정 |
| `-e` | 계정 유효 기간 지정 |
| `-f` | 비밀번호 만료 후 비활성 기간 지정 |
| `-G` | 보조 그룹 지정 |
| `-s` | 로그인 셸 지정 |

웹 자료의 예시는 `test` 계정에 `linux`라는 설명을 붙입니다.

```bash
useradd -c linux test
tail -2 /etc/passwd
```

출력에서 `test` 행의 다섯 번째 필드가 `linux`인지 확인합니다. 이미 존재하는 계정 이름은 사용하지 않도록 주의하세요.

## 3. 비밀번호 관리: `passwd`

`passwd`는 비밀번호를 설정하거나 변경하고 상태를 관리합니다.

```bash
passwd test       # test 계정의 비밀번호 변경
passwd -S test    # 비밀번호 상태 확인
passwd -l test    # 비밀번호 잠금
passwd -u test    # 비밀번호 잠금 해제
```

비밀번호 입력 시 화면에 입력 내용이 표시되지 않는 것이 정상입니다. 웹 자료의 상태 표시는 `PS`(설정됨), `NP`(비밀번호 없음), `LK`(잠김)입니다.

`passwd -d`는 비밀번호를 삭제하는 옵션이므로 잠금 옵션인 `-l`과 혼동하지 마세요. 잠금과 해제는 시스템에 영향을 주므로 실습 계정에서만 진행합니다.

## 4. 사용자 전환: `su`

`su`는 현재 세션에서 로그아웃하지 않고 다른 사용자로 전환합니다.

```bash
su root     # root로 전환
su - root   # root의 로그인 환경을 적용하여 전환
```

웹 자료에서는 `su root` 후 `pwd`가 `/home/test`를, `su - root` 후 `pwd`가 `/root`를 보여 줍니다. 즉, `-`를 사용한 예시는 **전환 대상의 로그인 환경**을 적용하는 차이를 보여 줍니다.

| 옵션 | 의미 |
| --- | --- |
| `-`, `-l`, `--login` | 대상 사용자의 로그인 환경 적용 |
| `-c` | 주어진 명령 실행 |
| `-s` | 사용할 셸 지정 |

## 5. 계정 변경과 삭제

### `usermod`: 계정 정보 변경

```bash
usermod [옵션] 설정값 계정명
```

| 옵션 | 변경할 정보 |
| --- | --- |
| `-c` | 설명 |
| `-d` | 홈 디렉터리 |
| `-e` | 계정 만료일 |
| `-f` | 비밀번호 만료 후 비활성 기간 |
| `-g` | 기본 그룹 |
| `-G` | 보조 그룹 |
| `-s` | 로그인 셸 |
| `-u` | UID |

웹 자료의 예시는 `test` 계정에 기록된 홈 디렉터리 경로를 변경합니다.

```bash
usermod -d /home/test2 test
tail -2 /etc/passwd
```

출력에서 계정의 홈 경로가 바뀌었는지 확인합니다. 이 예시는 계정 정보의 경로를 바꾸는 것이므로 기존 홈의 내용까지 옮겨졌다고 가정하지 마세요. `-G`로 그룹을 변경할 때도 기존 소속에 미칠 영향을 확인해야 합니다.

### `userdel`: 계정 삭제

```bash
userdel test       # 계정 삭제
userdel -r test    # 계정과 홈 디렉터리, 메일 스풀 삭제
```

`-r`은 홈 디렉터리의 내용도 삭제하므로 실제 사용자 계정에는 함부로 실행하지 마세요. 두 명령은 **각각 별도의 예시**이며 같은 계정에 연달아 실행하는 순서가 아닙니다.

## 6. 사용자 정보 조회

| 명령 | 확인할 내용 |
| --- | --- |
| `users` | 로그인한 사용자 이름 |
| `who` | 로그인 사용자와 접속 정보 |
| `who -H` | `who` 결과에 필드 제목 표시 |
| `who -u` | 사용자 유휴 시간 확인 |
| `w` | 로그인 사용자와 현재 작업 등 자세한 정보 |
| `whoami` | 현재 사용자 이름 |
| `id` | 현재 사용자의 UID, GID, 그룹 정보 |

예를 들어 `id` 출력의 `uid=0(root)`, `gid=0(root)`, `groups=0(root)`는 각각 사용자 ID, 기본 그룹 ID, 그룹 정보를 보여 줍니다.

## 7. 그룹 생성 및 관리

그룹을 이용하면 여러 사용자를 하나의 단위로 관리할 수 있습니다.

### `/etc/group`의 구조

```text
그룹명:비밀번호 관련 표시:GID:구성원
```

웹 자료의 `test2:x:1004:` 예시에서 그룹명은 `test2`, GID는 `1004`입니다.

### 그룹 관리 명령

| 명령 | 역할 |
| --- | --- |
| `groupadd -g 1004 test2` | GID를 지정하여 `test2` 그룹 생성 |
| `groupmod -n info test2` | 기존 `test2` 그룹의 이름을 `info`로 변경 |
| `groupdel test2` | `test2` 그룹 삭제 |
| `groups` | 현재 사용자가 속한 그룹 확인 |

`groupadd`의 `-o`는 웹 자료에서 `-g`와 함께 GID 중복을 허용하는 옵션으로 소개합니다. `groupmod -g`는 GID 변경에 사용합니다. 위 삭제 예시는 이름을 변경한 후의 단계가 아니라 별도의 예시입니다.
