# 디렉터리 및 파일 명령어

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 디렉터리·파일 내용을 정리했습니다. 아래 실습은 리눅스에서 진행하며, 파일을 만들거나 지우는 명령은 실습용 디렉터리에서만 실행하세요.

## 1. 디렉터리와 경로

디렉터리는 파일과 다른 디렉터리를 담아 정리하는 공간입니다. 명령에 대상을 지정할 때는 경로를 사용합니다.

| 구분 | 설명 | 예시 |
| --- | --- | --- |
| 절대 경로 | 루트 디렉터리 `/`부터 시작하는 경로 | `/home/test` |
| 상대 경로 | 현재 작업 디렉터리를 기준으로 지정하는 경로 | `./yum/vars` |
| `.` | 현재 디렉터리 | `cd .` |
| `..` | 한 단계 상위 디렉터리 | `cd ..` |
| `~` | 현재 사용자의 홈 디렉터리 | `cd ~` |

### 만들기·이동·확인

| 명령 | 역할 | 주요 옵션 |
| --- | --- | --- |
| `mkdir` | 디렉터리 생성 | `-p`: 필요한 상위 경로도 생성, `-m`: 권한 지정, `-v`: 생성 정보 출력 |
| `rmdir` | **빈** 디렉터리 삭제 | 내용이 있으면 삭제할 수 없음 |
| `cd` | 디렉터리 이동 | 절대 경로 또는 상대 경로 지정 |
| `pwd` | 현재 작업 디렉터리 출력 | `-L`: 논리 경로, `-P`: 심볼릭 링크를 따라간 실제 경로 |

웹 자료의 예시처럼 중간 디렉터리까지 한 번에 생성하고 위치를 확인합니다.

```bash
mkdir -p /home/test1/test2/test3
cd /home/test1/test2/test3
pwd
cd ..
pwd
```

첫 번째 `pwd`는 `/home/test1/test2/test3`, 두 번째는 그 상위인 `/home/test1/test2`를 나타냅니다. `/home`에 생성 권한이 없는 경우에는 실습용 위치에서 경로를 바꾸어 사용하세요.

## 2. 목록 확인: `ls`

```bash
ls [옵션] [디렉터리]
```

| 옵션 | 기능 |
| --- | --- |
| `-a` | 숨김 파일을 포함한 목록 출력 |
| `-l` | 권한, 링크 수, 소유자, 크기, 수정 시간 등 상세 정보 출력 |
| `-d` | 디렉터리의 내용 대신 디렉터리 자체 출력 |
| `-F` | 디렉터리에는 `/`, 실행 파일에는 `*` 등 유형 표시 |
| `-m` | 항목을 쉼표로 구분하여 출력 |
| `-r` | 정렬 순서를 반대로 출력 |
| `-R` | 하위 디렉터리까지 출력 |
| `-t` | 수정 시간을 기준으로 정렬 |

```bash
ls -l
ls -a
```

예를 들어 `-rw-r--r--`로 시작하는 행은 일반 파일의 상세 정보이고, `drwxr-xr-x`로 시작하는 행은 디렉터리의 상세 정보입니다. 뒤에는 소유자, 그룹, 크기, 수정 시간, 이름 등이 이어집니다.

## 3. 파일 복사·이동·삭제

| 명령 | 기본 형식 | 역할 |
| --- | --- | --- |
| `cp` | `cp [옵션] 원본 대상` | 파일 또는 디렉터리 복사 |
| `mv` | `mv [옵션] 원본 대상` | 이동 또는 이름 변경 |
| `rm` | `rm [옵션] 대상` | 파일 또는 디렉터리 삭제 |

### 자주 쓰는 옵션

| 옵션 | `cp` | `mv` | `rm` |
| --- | --- | --- | --- |
| `-i` | 덮어쓰기 전 확인 | 덮어쓰기 전 확인 | 삭제 전 확인 |
| `-f` | 덮어쓰기를 강제 | 덮어쓰기를 강제 | 확인 없이 삭제 |
| `-r` | 하위 디렉터리까지 복사 | — | 하위 디렉터리까지 삭제 |
| `-v` | — | 작업 과정 출력 | 작업 과정 출력 |
| `-u` | 대상보다 원본이 최신인 경우 등에 복사 | 대상보다 원본이 최신인 경우 등에 이동 | — |

`cp -p`는 원본의 모드와 시간 등의 정보를 유지하며 복사합니다. 웹 자료는 `cp -b`, `mv -b`를 기존 대상의 백업을 만드는 옵션으로도 소개합니다.

### 웹 자료의 명령 읽어 보기

```bash
cp -i /etc/passwd /root   # 복사할 대상이 이미 있으면 덮어쓰기 확인
mv test2.txt linux.txt    # 같은 위치에서 이름 변경
mv test1.txt /home        # 파일을 다른 디렉터리로 이동
rm -i test1.txt           # 확인 후 파일 삭제
```

실제 실행 시에는 쓰기 권한과 대상 파일의 존재 여부에 따라 결과가 달라집니다. 특히 `rm -r`과 `rm -f`는 삭제 범위를 반드시 확인하세요. `rmdir`는 빈 디렉터리만 지운다는 점과 구분합니다.

## 4. 파일 생성·유형 확인

### `touch`

`touch`는 파일이 없으면 빈 파일을 만들고, 파일이 있으면 시간 정보를 갱신합니다.

```bash
touch test.txt
touch -t 202010311045 test.txt
```

두 번째 명령은 웹 자료의 예시처럼 시간을 지정합니다. `-c`는 파일이 없을 때 새로 만들지 않고, `-a`와 `-m`은 각각 접근 시간과 수정 시간을 지정할 때 사용합니다.

### `file`

`file`은 파일의 유형을 확인합니다.

```bash
file test.txt
file -b test.txt
```

`-b`는 파일 이름을 제외하고 유형을 출력합니다. 웹 자료는 `-i`로 MIME 유형을 출력하는 방법도 소개합니다.

## 5. 파일과 명령 검색

| 명령 | 찾는 대상과 방식 |
| --- | --- |
| `find` | 지정한 경로에서 이름·종류·크기·시간 등의 조건으로 검색 |
| `locate` | 미리 만들어 둔 데이터베이스에서 파일 위치 검색 |
| `whereis` | 명령의 실행 파일, 소스, 매뉴얼 위치 검색 |
| `which` | 명령 실행 파일 또는 링크의 위치 검색 |

```bash
find / -name passwd -print
locate passwd
whereis ls
which ls
```

- `find`의 `-name`은 이름, `-type`은 유형, `-size`는 크기, `-empty`는 빈 파일이나 디렉터리 조건입니다.
- `find`에는 검색 결과를 삭제하는 `-delete`와 명령을 실행하는 `-exec`도 있습니다. 검색 결과를 먼저 확인한 후 사용해야 합니다.
- `locate`는 데이터베이스를 사용하므로 빠르지만, DB가 갱신되지 않았다면 현재 파일 상태와 검색 결과가 다를 수 있습니다. 웹 자료는 DB 갱신 명령으로 `updatedb`를 소개합니다.
- `find / ...`는 시스템 전체를 검색하므로 접근 권한이나 시스템 상태에 따라 출력과 오류가 달라질 수 있습니다.

### 링크 이해하기

웹 자료는 경로를 설명하면서 하드 링크와 심볼릭 링크를 비교합니다.

| 구분 | 하드 링크 | 심볼릭 링크 |
| --- | --- | --- |
| inode | 원본과 동일 | 원본과 다른 inode |
| 가리키는 대상 | 원본과 같은 파일 데이터 | 원본의 이름·경로 |
| 원본 이름 삭제 시 | 다른 하드 링크로 파일에 접근 가능 | 가리키는 경로가 없어지면 사용 불가 |

## 6. 파일 내용 보기

| 명령 | 역할 | 주요 사용법 |
| --- | --- | --- |
| `cat` | 파일 전체 출력 또는 내용 연결 | `-n`: 빈 줄 포함 행 번호, `-b`: 빈 줄 제외 행 번호 |
| `head` | 파일 앞부분 출력 | `-n 2`: 앞 2행, `-c 20`: 앞 20바이트 |
| `tail` | 파일 뒷부분 출력 | `-n 2`: 뒤 2행, `-f`: 추가되는 내용을 계속 확인 |
| `more` | 내용을 화면 단위로 보기 | `Space`: 다음 화면, `q`: 종료 |
| `less` | 내용을 화면 단위로 앞뒤 이동하며 보기 | 화살표·Page Up/Down 이동, `q`: 종료 |

웹 자료의 `linux.txt` 예시를 기준으로 읽어 봅니다.

```bash
cat -n linux.txt
head -n 2 linux.txt
tail -n 2 linux.txt
less linux.txt
```

`head`는 앞에서, `tail`은 뒤에서 줄을 선택합니다. `tail -f`는 계속 출력하는 방식이므로 실습 시 종료 방법을 확인하세요.

## 7. 내용 검색·가공

### 검색: `grep`

`grep`은 파일에서 패턴에 맞는 행을 검색합니다.

```bash
grep -n linux linux.txt
```

이 명령은 `linux`가 포함된 행과 행 번호를 출력합니다.

| 옵션 | 의미 |
| --- | --- |
| `-c` | 일치하는 행 수 |
| `-i` | 대소문자 구분 없이 검색 |
| `-l` | 일치하는 내용이 있는 파일 이름 |
| `-n` | 행 번호 출력 |
| `-v` | 일치하지 않는 행 출력 |
| `-w` | 단어 단위로 일치하는 패턴 검색 |

### 개수·정렬·추출·분할

| 명령 | 기능 | 웹 자료의 예시 |
| --- | --- | --- |
| `wc` | 행·단어·바이트 수 확인 | `wc -l linux.txt`: 행 수 |
| `sort` | 내용을 정렬해 출력 | `sort test.txt`: 오름차순 정렬 |
| `cut` | 지정한 위치 또는 필드 추출 | `cut -c 1-3 test.txt`: 각 행의 1~3번째 문자 |
| `split` | 파일을 여러 파일로 분할 | `split -l 3 linux.txt`: 3행씩 분할 |

`sort -n`은 숫자 기준 정렬, `sort -r`은 역순 정렬, `sort -u`는 정렬 후 중복 제거입니다. `cut -d`로 구분자를, `-f`로 필드를 지정할 수 있습니다. `split -b 20 linux.txt`는 20바이트 단위 분할 예시입니다.

> `split`은 분할 파일을 실제로 생성합니다. 같은 이름의 파일이 있는 위치에서 실행하지 않도록 실습 위치를 확인하세요.

## 8. 파일 비교

| 명령 | 비교 방식 | 알아둘 점 |
| --- | --- | --- |
| `diff 파일1 파일2` | 파일의 다른 내용을 비교 | 웹 자료에서 같으면 종료 코드 0, 다르면 1, 오류면 2 이상 |
| `cmp 파일1 파일2` | 바이트 단위 비교 | 처음 차이가 나는 위치를 확인 |
| `comm 파일1 파일2` | 행 단위 비교 | 정렬된 파일을 비교하며 각 파일에만 있는 행과 공통 행을 구분 |

`diff -i`는 대소문자를 구분하지 않고 비교하며, `diff -s`는 파일이 같을 때도 알립니다. `comm -1`, `-2`, `-3`은 각각 첫 번째 파일에만 있는 행, 두 번째 파일에만 있는 행, 공통 행의 출력을 생략합니다.

## 9. 리다이렉션과 파이프

### 리다이렉션: 입출력 방향 바꾸기

| 기호 | 기능 |
| --- | --- |
| `>` | 출력을 파일에 저장. 파일이 있으면 덮어씀 |
| `>>` | 출력을 파일 끝에 추가 |
| `<` | 파일을 입력으로 사용 |

```bash
cat test1.txt > test3.txt
cat test1.txt >> test3.txt
```

첫 번째 명령은 `test3.txt`를 덮어쓰고, 두 번째는 같은 내용을 끝에 덧붙입니다. `>`를 사용할 때 기존 내용이 사라지지 않도록 대상 파일을 확인하세요.

### 파이프: 명령 연결하기

`|`는 앞 명령의 출력을 뒤 명령의 입력으로 전달합니다.

```bash
ps aux | grep httpd
```

위 예시는 `ps aux` 결과에서 `httpd`가 포함된 행을 검색합니다. 웹 자료에는 검색 명령 자체가 결과에 나타나는 예도 있습니다.

세미콜론(`;`)은 한 줄에 여러 명령을 나열합니다. 웹 자료에 따르면 앞 명령이 실패해도 다음 명령을 실행하므로, 파이프처럼 출력을 전달하는 기호와 구분해야 합니다.

## 10. 복습

- 경로는 `/`부터 시작하면 절대 경로, 현재 위치를 기준으로 지정하면 상대 경로입니다.
- `cp`는 복사, `mv`는 이동·이름 변경, `rm`은 삭제입니다.
- `find`는 조건을 지정해 검색하고, `locate`는 기존 DB를 조회합니다.
- `head`는 앞부분, `tail`은 뒷부분, `grep`은 패턴이 포함된 행을 확인합니다.
- `>`는 덮어쓰기, `>>`는 추가, `|`는 명령의 출력을 다음 명령에 전달합니다.
