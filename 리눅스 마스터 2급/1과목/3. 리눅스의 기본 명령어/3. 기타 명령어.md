# 기타 명령어: 네트워크와 시스템

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 기타 명령어를 정리했습니다. 네트워크 조회 결과는 환경에 따라 달라지며, 시스템 시간 변경이나 메시지 전송은 다른 사용자에게 영향을 줄 수 있습니다.

## 1. 네트워크 명령어 한눈에 보기

| 궁금한 점 | 명령 | 확인 내용 |
| --- | --- | --- |
| 대상 호스트에 응답이 오는가? | `ping` | 호스트 간 연결 상태 |
| 목적지까지 어떤 경로를 거치는가? | `traceroute` | 목적지까지의 경로와 홉 |
| 도메인에 어떤 주소가 연결되는가? | `nslookup`, `dig`, `host` | DNS 질의 결과 |
| 이 시스템의 이름은 무엇인가? | `hostname` | 호스트 이름 |

## 2. 연결과 경로 확인

### `ping`: 응답 확인

```bash
ping -c 3 8.8.8.8
```

`-c 3`은 패킷을 세 번 보내는 옵션입니다. 웹 자료의 예시에서는 `3 packets transmitted, 3 received, 0% packet loss`로 전송 수, 수신 수, 손실률을 확인합니다. `time`은 응답 시간입니다.

| 옵션 | 의미 |
| --- | --- |
| `-c` | 전송 횟수 지정 |
| `-i` | 전송 간격 지정 |
| `-n` | 이름 대신 숫자 주소로 표시 |
| `-f` | 다량의 패킷 전송 |

웹 자료는 옵션 없이 실행하면 연속적으로 동작한다고 설명합니다. `-f`는 많은 패킷을 전송하므로 실습에서 무심코 사용하지 마세요. 응답 여부는 네트워크 환경과 대상 설정에 따라 달라집니다.

### `traceroute`: 목적지까지의 경로

```bash
traceroute 192.168.10.138
```

목적지까지 거치는 경로를 출력해 장애 구간을 살펴보는 데 사용합니다. 웹 자료의 예시처럼 출력 각 행의 번호는 경로상의 홉을 나타냅니다.

| 옵션 | 의미 |
| --- | --- |
| `-m` | 최대 홉 수 지정 |
| `-n` | 호스트 이름을 검색하지 않음 |
| `-p` | 시작 포트 번호 지정 |
| `-q` | 질의 패킷 수 지정 |
| `-w` | 응답 대기 시간 지정 |

위 IP 주소는 웹 자료의 예시이므로 실제 환경에서 같은 결과가 나온다고 가정하지 않습니다.

## 3. DNS 조회

DNS 조회 명령은 도메인 이름과 관련된 주소나 다른 레코드 정보를 확인할 때 사용합니다.

### 자주 보는 레코드

| 유형 | 웹 자료에서 설명한 내용 |
| --- | --- |
| `A` | IPv4 주소 |
| `AAAA` | IPv6 주소 |
| `MX` | 메일 서버 |
| `NS` | 네임 서버 |
| `SOA` | 도메인에 대한 선언 정보 |
| `PTR` | IP 주소에 대한 도메인 이름 응답 |
| `CNAME` | 별칭 |
| `TXT` | 도메인 이름과 연결된 텍스트 |
| `SRV` | 특정 서비스와 도메인 연결 정보 |

### `nslookup`

도메인 이름으로 IP 주소를 조회하거나 IP 주소로 도메인 이름을 조회합니다.

```bash
nslookup -type=a netnuri.com
```

웹 자료의 출력에서는 `Server`가 질의에 사용한 DNS 서버, `Name`이 조회한 이름, `Address`가 응답된 주소를 보여 줍니다. 주소는 시간이 지나거나 환경이 바뀌면 달라질 수 있습니다.

### `dig`

`dig`도 DNS 질의 결과를 확인하는 명령입니다.

```bash
dig netnuri.com
dig @168.126.63.1 netnuri.com
```

두 번째 예시의 `@168.126.63.1`은 질의할 DNS 서버를 지정합니다. 서버를 지정하지 않으면 웹 자료에서는 시스템의 `resolv.conf`에 설정된 네임 서버를 사용한다고 설명합니다.

출력의 `ANSWER SECTION`은 응답된 레코드를, `SERVER`는 질의에 사용한 서버를 확인하는 부분입니다. 웹 자료는 `A`, `MX`, `NS`, `SOA`, `TXT` 등의 유형을 소개합니다.

### `host`

```bash
host netnuri.com
```

DNS 서버를 이용해 도메인 이름에 대한 IP 주소를 조회합니다. 웹 자료에서는 주소와 메일 처리 서버가 함께 출력된 예시를 보여 줍니다.

| 옵션 | 의미 |
| --- | --- |
| `-t` | 조회할 레코드 유형 지정 |
| `-d` | 디버깅 정보 출력 |
| `-w` | DNS 서버의 응답 대기 |

### `hostname`

`hostname`은 호스트 이름을 확인하거나 변경하는 명령입니다. 먼저 조회 용도로 사용해 봅니다.

```bash
hostname
hostname -f    # FQDN 출력
hostname -s    # 짧은 형식의 이름 출력
```

웹 자료에는 `-d`(도메인 이름), `-i`(IP 주소), `-a`(별칭)도 소개되어 있습니다. 출력은 시스템 설정에 따라 달라집니다.

## 4. 날짜와 시간

### `date`: 시스템 날짜와 시간

```bash
date
```

현재 시스템 날짜와 시간을 출력합니다. 웹 자료는 `date`를 사용해 날짜와 시간을 변경하는 방법도 소개하지만, 시간 변경은 시스템에 영향을 주므로 여기서는 조회 예시를 먼저 익힙니다.

### `rdate`: 시간 서버 조회

```bash
rdate -p time.bora.net
```

원격 시간 서버의 정보를 가져오는 명령입니다. `-p`는 웹 자료에서 정보를 출력하되 시간을 설정하지 않는 옵션입니다. `-s`는 설정에 사용하는 옵션이므로 조회와 구분하세요. 서버 응답과 명령 사용 가능 여부는 환경에 따라 다릅니다.

### `cal`: 달력

```bash
cal
cal -y
```

옵션 없이 실행하면 현재 월의 달력을 표시합니다. 웹 자료에서 `-y`는 현재 연도의 모든 월을 출력하는 옵션입니다.

### `time`: 실행 시간

```bash
time ps
```

`ps`를 실행한 뒤 시간 정보를 출력합니다. 웹 자료의 항목은 다음과 같습니다.

| 항목 | 의미 |
| --- | --- |
| `real` | 전체 경과 시간 |
| `user` | 사용자 영역에서 실행된 시간 |
| `sys` | 커널에서 실행된 시간 |

## 5. 터미널과 메시지

| 명령 | 역할 | 예시 |
| --- | --- | --- |
| `tty` | 현재 단말 장치의 경로와 파일 이름 출력 | `tty` |
| `clear` | 터미널 화면 지우기 | `clear` |
| `wall` | 로그인한 사용자들에게 메시지 전송 | `wall Welcome to Linux..!!` |
| `write` | 지정한 사용자에게 메시지 전송 | `write test tty0` |
| `mesg` | 메시지 수신 여부 확인·제어 | `mesg`, `mesg y`, `mesg n` |

`tty`는 웹 자료에서 `/dev/pts/0`처럼 출력됩니다. `write`는 사용자와 단말을 지정하고, `wall`은 여러 로그인 사용자에게 알린다는 점이 다릅니다. 메시지 전송 명령은 다른 사람의 작업 화면에 나타날 수 있으므로 실습 전용 환경에서 사용하세요.

## 6. 복습

- 연결 응답은 `ping`, 목적지까지의 경로는 `traceroute`로 살펴봅니다.
- `nslookup`, `dig`, `host`는 DNS 조회에 사용하고, `hostname`은 시스템의 호스트 이름을 다룹니다.
- `date`는 날짜·시간, `cal`은 달력, `time`은 명령 실행 시간을 확인합니다.
- `tty`는 현재 단말, `wall`과 `write`는 메시지 전송, `mesg`는 메시지 수신 제어에 사용합니다.
