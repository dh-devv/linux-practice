# 기본 명령어 속성 노트

Oct 30, 2026 · @변동헌

## 사용자 계정 관리

명령 5개와 설정 파일 5개만 잡으면 이 영역의 대부분이 풀립니다.

| 명령 | 하는 일 | 꼭 외울 옵션 |
| --- | --- | --- |
| `useradd` | 계정 생성 | `-u` UID, `-g` 기본 그룹, `-G` 보조 그룹, `-d` 홈 디렉터리, `-s` 로그인 셸, `-c` 설명, `-e` 만료일, `-m` 홈 생성 |
| `passwd` | 비밀번호 설정 | `-l` 잠금, `-u` 잠금 해제, `-d` 비밀번호 삭제, `-S` 상태 확인, `-e` 즉시 만료 |
| `su` | 사용자 전환 | `su -`는 대상 사용자의 로그인 환경까지 적용, 옵션 없는 `su`는 현재 환경 유지 |
| `usermod` | 계정 정보 변경 | useradd와 같은 옵션, `-L` 잠금, `-U` 해제, `-aG` 보조 그룹 추가, `-l` 계정 이름 변경 |
| `userdel` | 계정 삭제 | `-r` 홈 디렉터리와 메일 스풀까지 삭제 |

| 파일 | 내용 |
| --- | --- |
| `/etc/default/useradd` | useradd의 기본값(기본 홈 위치, 기본 셸 등) |
| `/etc/login.defs` | UID·GID 범위, 비밀번호 만료 기본값, umask |
| `/etc/skel` | 새 계정의 홈 디렉터리에 복사되는 기본 파일(.bashrc 등) |
| `/etc/passwd` | 계정 정보. 7필드: 계정:x:UID:GID:설명:홈:셸 |
| `/etc/shadow` | 암호화된 비밀번호와 만료 정보. 9필드: 계정:해시:최종변경일:최소:최대:경고:비활성:만료일:예약 |

- UID 0은 root, 1\~999는 시스템 계정, 일반 사용자는 1000부터 시작합니다.
- 로그인 사용자 조회: `users`(이름만), `who`(접속 정보), `w`(접속자의 작업까지), `whoami`(내 계정), `id`(UID·GID·소속 그룹)
- `passwd -d`는 비밀번호를 지워 오히려 위험합니다. 잠금은 `passwd -l` 또는 `usermod -L`입니다.

## 그룹 관리

그룹 정보는 `/etc/group`에 있고, 사용자의 기본 그룹은 `/etc/passwd`의 GID로 정해집니다.

| 명령 | 하는 일 | 핵심 옵션 |
| --- | --- | --- |
| `groupadd` | 그룹 생성 | `-g` GID 지정 |
| `groupmod` | 그룹 정보 변경 | `-n` 이름 변경, `-g` GID 변경 |
| `groupdel` | 그룹 삭제 | 어떤 사용자의 기본 그룹이면 삭제할 수 없음 |
| `groups` | 소속 그룹 출력 | 사용자 이름을 주면 그 사용자의 그룹 |

- `/etc/group` 형식은 그룹이름:x:GID:구성원 목록 4필드입니다.
- 그룹 비밀번호는 `/etc/gshadow`에 저장됩니다.
- 보조 그룹에 추가하려면 `usermod -aG 그룹 사용자`입니다. `-a` 없이 `-G`만 쓰면 기존 보조 그룹이 덮어써집니다.
- `usermod -g`는 기본 그룹을 바꿉니다.

## 디렉터리와 경로

경로는 `/`로 시작하면 절대 경로, 아니면 현재 위치 기준의 상대 경로입니다.

| 명령 | 하는 일 | 핵심 옵션 |
| --- | --- | --- |
| `mkdir` | 디렉터리 생성 | `-p` 중간 경로까지 한 번에 생성, `-m` 권한 지정 |
| `rmdir` | 빈 디렉터리 삭제 | `-p` 상위의 빈 디렉터리까지 삭제 |
| `cd` | 디렉터리 이동 | 인자 없음 또는 `~`는 홈, `-`는 직전 위치, `..`는 상위, `.`는 현재 |
| `pwd` | 현재 절대 경로 출력 | `-P` 심볼릭 링크를 풀어서 실제 경로 출력 |

- `mkdir -p /a/b/c`처럼 경로 중간이 없어도 한 번에 만들 수 있습니다.
- 내용이 있는 디렉터리는 `rmdir`로 지울 수 없고 `rm -r`을 써야 합니다.

## 파일 관리

`ls`, `cp`, `mv`, `rm`은 옵션 한두 개 차이로 정답이 갈리는 문제가 자주 나옵니다.

| 명령 | 하는 일 | 핵심 옵션 |
| --- | --- | --- |
| `ls` | 목록 출력 | `-l` 상세, `-a` 숨김 파일 포함, `-R` 하위 디렉터리까지, `-t` 수정 시간순, `-i` inode 번호, `-d` 디렉터리 자체, `-h` 읽기 쉬운 크기 |
| `cp` | 복사 | `-r` 디렉터리 복사, `-p` 권한·시간 유지, `-i` 덮어쓰기 확인, `-f` 강제, `-u` 새 파일만 |
| `mv` | 이동 및 이름 변경 | `-i` 덮어쓰기 확인, `-f` 강제 |
| `rm` | 삭제 | `-r` 디렉터리, `-f` 확인 없이 삭제, `-i` 삭제 전 확인 |
| `touch` | 빈 파일 생성, 시간 갱신 | `-t` 시간 지정 |
| `file` | 파일 종류 확인 | 확장자가 아닌 내용을 보고 판단 |

- `mv`는 같은 디렉터리 안에서 쓰면 이름 변경입니다. 별도의 rename 명령으로 외우지 않아도 됩니다.
- 파일이 이미 있는 상태에서 `touch`를 쓰면 내용은 그대로이고 수정 시간만 바뀝니다.
- `ls -l` 첫 글자는 파일 종류입니다. `-` 일반 파일, `d` 디렉터리, `l` 심볼릭 링크, `b` 블록 장치, `c` 문자 장치입니다.

## 검색과 링크

네 검색 명령은 찾는 대상과 속도가 다릅니다. 이 차이가 곧 문제입니다.

| 명령 | 찾는 대상 | 특징 |
| --- | --- | --- |
| `find` | 파일 시스템 전체 | 실시간으로 디렉터리를 탐색해 느리지만 정확하고 조건이 다양함 |
| `locate` | 파일 이름 | 미리 만든 DB를 조회해 빠르지만 최신 변경이 반영되지 않을 수 있음. `updatedb`로 DB 갱신 |
| `whereis` | 명령의 실행 파일, 소스, 매뉴얼 위치 | 지정된 표준 경로만 검색 |
| `which` | 명령의 실행 파일 경로 | PATH 환경 변수 안에서만 검색 |

`find`의 자주 나오는 조건입니다.

| 조건 | 의미 |
| --- | --- |
| `-name "*.conf"` | 이름으로 검색(와일드카드는 따옴표로 감쌈) |
| `-type f` / `-type d` | 일반 파일 / 디렉터리 |
| `-user 계정` | 소유자가 해당 계정 |
| `-perm 644` | 권한이 정확히 644 |
| `-size +10M` | 10MB보다 큼 |
| `-mtime -7` | 최근 7일 이내 수정 |

하드 링크와 심볼릭 링크는 `ln`으로 만듭니다.

| 구분 | 하드 링크 | 심볼릭(소프트) 링크 |
| --- | --- | --- |
| 만드는 법 | `ln 원본 링크` | `ln -s 원본 링크` |
| inode | 원본과 같음 | 원본과 다름(경로를 담은 별도 파일) |
| 원본 삭제 시 | 내용에 계속 접근 가능 | 링크가 깨짐 |
| 파일 시스템 경계 | 같은 파일 시스템 안에서만 | 넘어갈 수 있음 |
| 디렉터리 대상 | 불가 | 가능 |

## 파일 내용 출력

파일 크기와 보는 방향에 따라 고르면 됩니다.

| 명령 | 하는 일 | 핵심 옵션 |
| --- | --- | --- |
| `cat` | 전체 내용을 한 번에 출력, 파일 이어 붙이기 | `-n` 줄 번호 |
| `head` | 앞부분 출력(기본 10줄) | `-n 5` 또는 `-5` |
| `tail` | 뒷부분 출력(기본 10줄) | `-n 5`, `-f` 파일에 추가되는 내용을 실시간으로 출력(로그 감시) |
| `more` | 한 화면씩 출력 | 앞으로만 이동, Space로 다음 화면 |
| `less` | 한 화면씩 출력 | 앞뒤 이동 가능, `/문자열`로 검색, `q`로 종료 |

- `tail -f`는 로그 확인 문제에 자주 나옵니다. 종료는 Ctrl+C입니다.
- `cat a b > c`는 a와 b를 이어 붙여 c에 저장합니다.

## 시험 직전 암기 포인트

헷갈리는 쌍을 한 줄씩 비교해 두면 선택지에서 바로 걸러집니다.

| 헷갈리는 쌍 | 구분 |
| --- | --- |
| `useradd -g` / `-G` | 기본 그룹 / 보조 그룹 |
| `usermod -G` / `-aG` | 보조 그룹을 덮어씀 / 기존에 추가 |
| `usermod -L` / `passwd -d` | 계정 잠금 / 비밀번호 삭제(잠금이 아님) |
| `userdel` / `userdel -r` | 계정만 삭제 / 홈과 메일 스풀까지 삭제 |
| `su` / `su -` | 현재 환경 유지 / 대상 사용자의 로그인 환경 적용 |
| `/etc/passwd` / `/etc/shadow` | 7필드 계정 정보 / 9필드 비밀번호 해시와 만료 정보 |
| `find` / `locate` | 실시간 탐색 / DB 조회(빠르지만 최신 반영이 늦음) |
| `which` / `whereis` | PATH 안의 실행 파일 / 실행 파일, 소스, 매뉴얼 위치 |
| `more` / `less` | 앞으로만 이동 / 앞뒤 이동과 검색 |
| `head` / `tail -f` | 앞부분 보기 / 뒷부분 실시간 감시 |
| `rmdir` / `rm -r` | 빈 디렉터리만 / 내용이 있어도 삭제 |
| 하드 링크 / 심볼릭 링크 | inode 공유, 원본 삭제해도 유지 / 경로 참조, 원본 삭제하면 깨짐 |

실제 시험은 보기에서 틀린 설명을 고르는 형태가 많으니, 위 쌍을 반대로 바꾼 문장이 오답 보기로 나온다고 생각하고 보면 됩니다.
