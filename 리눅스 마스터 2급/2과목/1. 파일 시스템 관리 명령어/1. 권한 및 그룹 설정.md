# 권한 및 그룹 설정

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 사용자 권한·그룹 설정 내용을 정리했습니다. 계정과 그룹의 생성·관리는 [1과목 계정 관리](../../1과목/3.%20리눅스의%20기본%20명령어/1.%20사용자%20생성%20및%20계정%20관리.md)를 함께 참고하세요. 권한이나 소유권을 바꾸는 명령은 실습용 파일에서만 실행합니다.

## 1. 파일 속성 읽기

`ls -l`은 파일 유형, 권한, 소유자, 그룹, 크기 등을 보여 줍니다.

```text
-rw-r--r--  1 root root 45 10월 11 13:44 linux.txt
```

| 부분 | 뜻 |
| --- | --- |
| `-` | 파일 유형. `-`는 일반 파일, `d`는 디렉터리, `l`은 심볼릭 링크 |
| `rw-r--r--` | 소유자·그룹·그 외 사용자의 허가권 |
| `1` | 링크 수 |
| `root root` | 사용자 소유자와 그룹 소유자 |
| `45` | 파일 크기 |
| 날짜와 이름 | 마지막 수정 시간과 파일 이름 |

권한을 세 글자씩 읽으면 `rw-`는 소유자 읽기·쓰기, `r--`는 그룹 읽기, 마지막 `r--`는 그 외 사용자 읽기입니다.

## 2. 소유권: `chown`, `chgrp`

| 명령 | 기능 |
| --- | --- |
| `chown` | 사용자 소유자 또는 사용자와 그룹 소유자 변경 |
| `chgrp` | 그룹 소유자 변경 |

웹 자료의 예시에서 `test` 사용자와 그룹이 존재한다고 가정합니다.

```bash
ls -l linux.txt
chown test linux.txt
chgrp test linux.txt
ls -l linux.txt
```

변경 전후 소유자와 그룹을 비교합니다. 두 명령의 `-R`은 하위 디렉터리까지 변경하므로 사용 범위를 특히 주의합니다.

## 3. 허가권: `chmod`

허가권은 읽기(`r`), 쓰기(`w`), 실행(`x`)으로 나누며, 기호 또는 숫자로 지정합니다.

```bash
chmod 755 linux.txt
ls -l linux.txt
```

`755`는 소유자 `rwx`, 그룹 `r-x`, 그 외 사용자 `r-x`에 해당합니다. 웹 자료의 예처럼 `chmod u-x,g+w,o-x linux.txt`는 소유자 실행 제거, 그룹 쓰기 추가, 그 외 사용자 실행 제거를 지정합니다.

| 숫자 | 권한 |
| --- | --- |
| `7` | 읽기·쓰기·실행 (`rwx`) |
| `5` | 읽기·실행 (`r-x`) |
| `4` | 읽기 (`r--`) |

기호 모드에서 `u`, `g`, `o`는 각각 소유자, 그룹, 그 외 사용자를 뜻합니다. `+`는 권한 추가, `-`는 권한 제거입니다.

## 4. 기본 권한과 `umask`

`umask`는 새 파일이나 디렉터리를 만들 때 기본 권한에서 제한할 부분을 정합니다.

```bash
umask
umask -S
```

웹 자료의 `umask 022` 예에서는 기본 파일 권한이 `644`, 디렉터리 권한이 `755`입니다. `-S`는 기호 형식으로 확인합니다. 값은 시스템과 설정에 따라 다릅니다.

## 5. 특수 허가권

| 종류 | 표시 | 역할 |
| --- | --- | --- |
| SetUID | 소유자 실행 위치의 `s` 또는 `S` | 실행 파일에 설정하면 실행 중 파일 소유자의 권한을 사용 |
| SetGID | 그룹 실행 위치의 `s` 또는 `S` | 실행 파일에 설정하면 실행 중 파일의 그룹 권한을 사용 |
| Sticky bit | 그 외 사용자 실행 위치의 `t` 또는 `T` | 공유 디렉터리 안의 파일 삭제를 제한 |

소문자 표시는 해당 위치에 실행 권한도 있음을, 대문자 표시는 실행 권한이 없음을 나타냅니다. 웹 자료의 `chmod 4744 linux.txt` 예시는 SetUID 표시를 살펴보기 위한 것입니다. 특수 권한은 보안에 영향을 줄 수 있으므로 실제 시스템 파일에서 임의로 설정하지 않습니다.

## 6. 디스크 쿼터

쿼터는 파일 시스템에서 사용자나 그룹이 사용할 **블록 용량과 inode 수**를 제한합니다.

| 구분 | 의미 |
| --- | --- |
| soft limit | 유예 기간 동안 일시적으로 초과할 수 있는 제한 |
| hard limit | 초과할 수 없는 제한 |

| 명령 | 역할 |
| --- | --- |
| `quotaon` / `quotaoff` | 쿼터 활성화 / 중지 |
| `quotacheck` | 사용량 검사 및 기록 갱신 |
| `edquota` / `setquota` | 사용자·그룹 쿼터 설정 |
| `repquota` | 쿼터 사용량과 설정 요약 |
| `xfs_quota` | XFS 파일 시스템의 쿼터 관리 |

웹 자료에서는 `/etc/fstab`의 `usrquota` 설정과 XFS의 `xfs_quota -x -c 'report -h' /data/disk1` 예시를 소개합니다. 실제 설정은 파일 시스템과 마운트 구성에 영향을 주므로 개념과 역할부터 익히세요.

XFS 예시에 나오는 `bsoft`와 `bhard`는 블록 용량의 soft·hard 제한이며, `isoft`와 `ihard`는 inode 수의 soft·hard 제한입니다. `-u`와 `-g`는 각각 사용자와 그룹 대상을 구분합니다.
