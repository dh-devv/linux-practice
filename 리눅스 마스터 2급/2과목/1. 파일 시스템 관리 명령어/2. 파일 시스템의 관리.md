# 파일 시스템의 관리

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)를 바탕으로 정리했습니다. 파티션 생성, 포맷, 복구, 마운트 설정 변경은 데이터 손실이나 부팅 문제를 일으킬 수 있으므로 실제 장치에 예시를 그대로 실행하지 마세요.

## 1. 파일 시스템과 구성

파일 시스템은 저장 매체의 파일과 자료를 저장하고 찾아 관리하기 위한 체계입니다. 웹 자료는 다음 구성 요소를 소개합니다.

| 구성 요소 | 역할 |
| --- | --- |
| 슈퍼블록 | 블록 수, 블록 그룹 수, inode 수 등 파일 시스템 정보 |
| 그룹 설명 테이블 | 블록 그룹과 빈 블록·inode 등에 관한 정보 |
| 블록·inode 비트맵 | 블록과 inode의 사용 현황 |
| inode 테이블 | inode 관련 정보 |
| 데이터 블록 | 실제 파일 내용 |

### 종류 비교

| 종류 | 웹 자료의 설명 |
| --- | --- |
| ext2 | 블록 그룹과 inode를 사용하는 리눅스 파일 시스템 |
| ext3 | ext2에 저널링 기능을 추가한 파일 시스템 |
| ext4 | ext3의 확장 버전으로 향상된 블록 할당 등을 지원 |
| JFS, XFS | 웹 자료에서 소개한 저널링 파일 시스템 |
| NFS, SMB/CIFS | 네트워크를 통해 파일을 공유하는 기술 |
| ISO 9660, UDF | 광학 매체에 사용하는 파일 시스템 |

## 2. 파티션과 파일 시스템 생성

| 명령 | 역할 |
| --- | --- |
| `fdisk -l` | 디스크와 파티션 정보를 조회 |
| `fdisk` | 파티션 생성·수정·삭제 |
| `mkfs -t ext4 장치` | 지정 장치에 ext4 파일 시스템 생성 |
| `mke2fs -t ext4 장치` | ext 계열 파일 시스템 생성 |
| `mkfs.xfs 장치` | XFS 파일 시스템 생성 |

**파티션을 나누는 작업과 파일 시스템을 생성하는 작업은 다릅니다.** 특히 `mkfs` 계열은 대상 장치의 기존 데이터에 영향을 줍니다. 위의 `장치`는 설명용 자리 표시자이며 실행할 값이 아닙니다.

## 3. 검사와 복구

| 명령 | 용도 |
| --- | --- |
| `fsck` | 파일 시스템 검사와 복구 |
| `e2fsck` | ext 계열 파일 시스템 검사와 복구 |
| `xfs_repair` | XFS 파일 시스템 검사와 복구 |

웹 자료는 `e2fsck -n`의 질의에 모두 아니요로 답하는 옵션과 `xfs_repair -n`의 수정 없이 검사하는 옵션을 소개합니다. 검사·복구도 대상과 마운트 상태를 확인한 후 해당 파일 시스템의 절차에 따라 진행해야 합니다.

## 4. 마운트와 용량 조회

**마운트**는 장치의 파일 시스템을 디렉터리에 연결하는 작업이고, `umount`는 연결을 해제합니다.

```text
mount -t ext4 /dev/sdb1 /mnt
umount /dev/sdb1
```

위는 웹 자료의 장치 이름을 사용한 **설명용 예시**입니다. `/dev/sdb1`과 `/mnt`는 실제 시스템에서 다른 용도일 수 있습니다. `mount -o ro`는 읽기 전용 마운트 옵션입니다.

다음 명령은 마운트된 파일 시스템의 사용량을 확인합니다.

```bash
df -h
df -hT
df -i
```

`-h`는 읽기 쉬운 크기, `-T`는 파일 시스템 유형, `-i`는 inode 사용 정보를 보여 줍니다.

## 5. `/etc/fstab`

웹 자료에서 `/etc/fstab`은 부팅 시 마운트할 파일 시스템 등의 설정을 저장합니다.

```text
/dev/sdb1  /home  ext3  defaults  0  0
```

| 순서 | 예시 | 의미 |
| --- | --- | --- |
| 1 | `/dev/sdb1` | 장치 |
| 2 | `/home` | 마운트 지점 |
| 3 | `ext3` | 파일 시스템 유형 |
| 4 | `defaults` | 마운트 옵션 |
| 5 | `0` | dump 관련 설정 |
| 6 | `0` | 파일 시스템 점검 순서 관련 설정 |

옵션으로 `ro`(읽기 전용), `rw`(읽기·쓰기), `auto`와 `noauto` 등이 있습니다. 이 파일의 예시는 기존 시스템에 복사하는 설정이 아닙니다.

## 복습

`fdisk`는 파티션, `mkfs`는 파일 시스템 생성, `fsck`는 검사·복구, `mount`는 연결, `df`는 사용량 확인입니다.
