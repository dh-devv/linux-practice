# 셸의 개념 및 종류

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 셸 내용을 정리했습니다.

## 1. 셸이란?

셸은 사용자가 입력한 명령을 해석하여 커널에 전달하고, 사용자가 시스템과 상호작용할 수 있도록 하는 프로그램입니다.

```text
사용자 → 명령 입력 → 셸 → 커널 → 실행 결과
```

셸은 로그인 환경을 제공하며, 스크립트 작성과 리다이렉션·파이프 같은 기능도 지원합니다. 프롬프트는 셸이 명령을 입력받을 준비가 되었음을 보여 주는 표시입니다.

## 2. 주요 셸

| 계열 | 셸 | 특징 |
| --- | --- | --- |
| 본 셸 계열 | sh | 유닉스의 본 셸 |
| 본 셸 계열 | ksh | 본 셸의 확장. 명령 완성과 히스토리 지원 |
| 본 셸 계열 | bash | GNU 프로젝트의 본 셸 기반 셸. 자동 완성, 편집, 히스토리 지원 |
| 본 셸 계열 | zsh | 본 셸 계열의 확장. 자동 완성과 히스토리 기능 지원 |
| C 셸 계열 | csh | C 언어의 특징을 포함하며 별칭과 작업 제어 지원 |
| C 셸 계열 | tcsh | C 셸의 확장. 명령 편집과 자동 완성 지원 |

## 3. 셸 확인과 변경

```bash
cat /etc/shells
echo "$SHELL"
```

`/etc/shells`에서 사용할 수 있는 셸 목록을 확인하고, `$SHELL`에서 로그인 셸로 설정된 경로를 확인합니다. 계정 정보 파일인 `/etc/passwd`의 마지막 필드에도 로그인 셸이 있습니다.

웹 자료에서 `chsh -l`은 셸 목록, `chsh -s 셸경로`는 셸 변경에 사용합니다. 관리자용 `usermod -s /bin/csh test`는 `test`의 로그인 셸을 변경하는 예시입니다. **셸 변경은 계정 설정에 영향을 주므로** 사용 가능한 셸과 대상 계정을 먼저 확인하세요.

## 복습

셸은 명령을 해석하는 프로그램이고, `bash`, `ksh`, `zsh`는 본 셸 계열, `csh`, `tcsh`는 C 셸 계열로 소개됩니다.
