# 셸 환경 설정

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 환경변수와 Bash 기능을 정리했습니다. 실제 설정 파일은 배포판과 로그인 방식에 따라 다를 수 있습니다.

## 1. 셸 변수와 환경변수

변수는 이름과 값을 이용해 셸이나 프로그램에서 필요한 설정을 보관합니다. `export`한 변수는 실행하는 하위 프로그램에 환경변수로 전달할 수 있습니다.

| 변수 | 역할 |
| --- | --- |
| `HOME` | 사용자 홈 디렉터리 |
| `PATH` | 명령을 찾는 경로 |
| `SHELL` | 로그인 셸 |
| `USER` | 사용자 이름 |
| `LANG` | 언어 관련 설정 |
| `DISPLAY` | X 윈도 출력 대상 |
| `PS1`, `PS2` | 기본 및 보조 프롬프트 |
| `TERM`, `TMOUT` | 터미널 종류와 자동 로그아웃 시간 |

### 확인·설정·삭제

```bash
echo "$HOME"
test=linux
export test
echo "$test"
unset test
```

먼저 변수를 만들고 `export`로 환경에 등록한 다음 값을 확인합니다. `unset`은 변수를 제거합니다.

웹 자료는 `export PATH=$PATH:/root/linux`로 기존 PATH 뒤에 경로를 추가하는 예도 제공합니다. 실제로 실행하면 현재 셸의 명령 검색 경로가 바뀝니다.

## 2. Bash 설정 파일

| 파일 | 웹 자료에서 설명하는 역할 |
| --- | --- |
| `/etc/profile` | 모든 사용자의 셸 환경 관련 설정 |
| `/etc/bashrc` | 전역 별칭과 Bash 함수 관련 설정 |
| `~/.bash_profile` | 개별 사용자 셸 환경 설정 |
| `~/.bashrc` | 개별 사용자 별칭과 Bash 함수 설정 |
| `~/.bash_logout` | 로그아웃 직전 설정 |
| `~/.bash_history` | 사용자가 입력한 명령 이력 |

## 3. 명령 이력과 별칭

```bash
history
history 3
alias pp='ls -l'
pp
unalias pp
```

`history`는 이력을 보여 주고 `history 3`은 최근 세 항목을 확인합니다. `alias`는 긴 명령을 짧은 이름으로 지정하며 `unalias`는 해당 별칭을 제거합니다.

| 이력 표기 | 기능 |
| --- | --- |
| `!!` | 마지막 명령 다시 실행 |
| `!n` | 이력 번호 `n`의 명령 실행 |
| `!문자열` | 해당 문자열로 시작하는 최근 명령 실행 |

이력 확장은 명령을 **실제로 다시 실행**하므로 삭제·변경 명령이 재실행되지 않도록 주의합니다. `HISTSIZE`, `HISTFILE`, `HISTFILESIZE`는 이력 크기나 저장 위치 관련 변수입니다.

| 변수 | 역할 |
| --- | --- |
| `HISTSIZE` | 현재 셸의 이력 크기 |
| `HISTFILE` | 이력을 저장하는 파일 위치 |
| `HISTFILESIZE` | 이력 파일의 크기 설정 |
| `HISTCONTROL` | 중복 명령 등의 기록 방식 |
| `HISTTIMEFORMAT` | 이력 시간의 표시 형식 |

## 4. 프롬프트

웹 자료의 `[root@localhost ~]#` 예시는 사용자, 호스트, 현재 디렉터리 등을 표시합니다. Bash의 `PS1`에 사용하는 표기에는 `\u`(사용자), `\h`(호스트), `\w`(현재 경로), `\t`(시간)가 있습니다.
