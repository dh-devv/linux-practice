# 프로세스의 개념 및 유형

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 프로세스 내용을 정리했습니다.

## 1. 프로세스

프로세스는 CPU를 할당받아 실행 중인 프로그램입니다. 각 프로세스에는 식별을 위한 **PID**가 있고, 부모 프로세스의 식별 번호는 **PPID**로 확인할 수 있습니다.

웹 자료는 `systemd`가 PID 1로 시작하는 시스템을 예시로 소개합니다. PID 1의 프로그램은 시스템 구성에 따라 다를 수 있습니다.

## 2. 포그라운드와 백그라운드

| 구분 | 설명 |
| --- | --- |
| 포그라운드 | 터미널에서 명령 결과를 기다리며 사용하는 일반적인 방식 |
| 백그라운드 | 작업이 실행되는 동안 같은 셸에서 다른 명령을 입력할 수 있는 방식 |

명령 뒤에 `&`를 붙이면 백그라운드 실행을 요청할 수 있습니다. 작업의 상태는 `jobs`, 전환은 `fg`와 `bg`로 확인·제어합니다.

## 3. 프로세스 생성과 실행

| 호출 | 역할 | PID 관점 |
| --- | --- | --- |
| `fork()` | 기존 프로세스를 바탕으로 자식 프로세스 생성 | 부모와 다른 PID를 가진 자식이 생김 |
| `exec()` | 호출한 프로세스의 실행 내용을 새 프로그램으로 교체 | 새 프로세스를 만들지 않고 기존 PID를 유지 |

## 4. 데몬

데몬은 백그라운드에서 동작하며 서비스 요청 등에 대응하는 프로세스입니다.

| 방식 | 웹 자료의 설명 |
| --- | --- |
| standalone | 서비스가 독립적으로 실행되어 요청을 기다림 |
| `(x)inetd` | 상위 데몬이 요청에 따라 다른 서비스를 실행·관리하는 방식 |

웹 자료의 `/etc/init.d`, `/etc/xinetd.d` 경로와 데몬 방식은 예시 환경의 구성으로 이해합니다.

## 5. 시그널

시그널은 이벤트를 프로세스에 전달하는 신호입니다.

| 번호 | 시그널 | 웹 자료의 설명 |
| --- | --- | --- |
| 1 | `SIGHUP` | 터미널 연결 종료 등 |
| 2 | `SIGINT` | 인터럽트. `Ctrl+C` |
| 3 | `SIGQUIT` | 실행 중지. `Ctrl+\` |
| 6 | `SIGABRT` | 비정상 종료 |
| 9 | `SIGKILL` | 강제 종료 |
| 14 | `SIGALRM` | 알람 |

`kill`은 지정한 PID에 시그널을 보내는 명령입니다. 강제 종료는 저장되지 않은 작업에 영향을 줄 수 있으므로 대상과 목적을 확인하세요.
