# 에디터의 종류

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 편집기 설명을 정리했습니다.

## 1. 에디터란?

에디터는 텍스트 파일을 만들고 수정하는 도구입니다. 리눅스의 설정과 명령은 텍스트로 다루는 경우가 많아 편집기를 익히는 것이 유용합니다.

## 2. 편집기 비교

| 편집기 | 웹 자료의 특징 |
| --- | --- |
| vi | 명령·입력·ex 모드를 사용하는 화면 편집기 |
| vim | vi와 호환되며 문법 강조, 검색 강조, 다중 되돌리기 등을 제공 |
| pico | 메뉴형 편집기로 바로 텍스트 입력·수정 가능 |
| nano | pico와 유사한 텍스트 모드 편집기. 화면 아래에 단축키 안내 |
| emacs | 여러 키 조합을 사용하고 확장성이 높은 편집기 |
| gedit | GNOME 계열의 그래픽 텍스트 편집기 |
| xedit | 웹 자료에서 소개한 X 윈도 편집기 |

**핵심 차이:** vi는 현재 모드에 따라 같은 키의 역할이 달라집니다. nano와 pico는 화면의 키 안내를 보며 바로 입력할 수 있는 방식으로 소개됩니다. 설치 여부와 실제 동작은 환경에 따라 다릅니다.
