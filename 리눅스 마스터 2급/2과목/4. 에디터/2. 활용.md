# 에디터 활용

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 vi, pico, nano, emacs 사용법을 정리했습니다. 예시는 실습용 텍스트 파일에서 따라 해 보세요.

## 1. vi의 세 가지 모드

```bash
vi linux.txt
```

| 모드 | 목적 | 들어가는 방법 |
| --- | --- | --- |
| 명령 모드 | 이동, 복사, 삭제 등 | `Esc` |
| 입력 모드 | 텍스트 입력 | 명령 모드에서 `i`, `a`, `o` 등 |
| ex 모드 | 저장, 종료, 치환 등 | 명령 모드에서 `:` |

### 처음 편집해 보기

1. `vi linux.txt`로 파일을 엽니다.
2. `i`를 눌러 입력 모드로 들어가 내용을 입력합니다.
3. `Esc`를 눌러 명령 모드로 돌아갑니다.
4. `:wq`를 입력하고 Enter를 눌러 저장 후 종료합니다.

| 명령 | 기능 |
| --- | --- |
| `:w` | 저장 |
| `:q` | 종료. 저장하지 않은 변경이 있으면 종료되지 않을 수 있음 |
| `:q!` | 변경을 저장하지 않고 종료 |
| `:wq` | 저장 후 종료 |
| `i` / `a` | 커서 앞 / 뒤에서 입력 |
| `o` / `O` | 현재 행 아래 / 위에 새 행을 열어 입력 |
| `h`, `j`, `k`, `l` | 왼쪽, 아래, 위, 오른쪽으로 이동 |
| `yy` / `dd` / `p` | 행 복사 / 행 삭제 / 붙여넣기 |
| `u` | 되돌리기 |
| `/linux` | `linux` 검색. `n`은 다음 일치 항목 |
| `:%s/old/new/g` | 파일 전체에서 `old`를 `new`로 치환 |

`:q!`, `dd`, 전체 치환은 내용이 사라지거나 바뀔 수 있으므로 실습 파일에서 확인합니다.

## 2. nano와 pico

```bash
nano linux.txt
```

화면 아래 `^` 표기는 `Ctrl`을 의미합니다.

| 키 | 기능 |
| --- | --- |
| `Ctrl+O` | 저장 |
| `Ctrl+X` | 종료 |
| `Ctrl+W` | 검색 |
| `Ctrl+K` | 현재 행 또는 선택된 내용 자르기 |
| `Ctrl+U` | 잘라 둔 내용 붙여넣기 |
| `Ctrl+G` | 도움말 |

웹 자료는 pico에서도 저장·종료·검색 등에 같은 형태의 단축키를 소개합니다. 실제 편집기 화면의 안내를 함께 확인하세요.

## 3. emacs

```bash
emacs linux.txt
```

`Ctrl+X`를 누른 다음 이어서 다른 키를 누르는 조합을 사용합니다.

| 순서 | 기능 |
| --- | --- |
| `Ctrl+X`, `Ctrl+F` | 파일 찾기 |
| `Ctrl+X`, `Ctrl+S` | 저장 |
| `Ctrl+X`, `Ctrl+C` | 종료 |
| `Ctrl+A` / `Ctrl+E` | 행의 시작 / 끝으로 이동 |
