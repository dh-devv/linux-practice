# 패키지로 프로그램 설치 및 삭제

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 패키지 관리 내용을 정리했습니다. 설치·삭제·업그레이드는 시스템을 변경하므로 실습 환경에서 패키지 이름과 배포판을 확인한 후 진행하세요.

## 1. 패키지와 배포판

패키지는 프로그램을 설치하고 관리하기 위한 형태입니다. 배포판 계열에 따라 사용하는 패키지 형식과 도구가 다릅니다.

| 계열 | 웹 자료의 배포판 예시 | 도구 | 형식 |
| --- | --- | --- | --- |
| Red Hat 계열 | RHEL, CentOS, Fedora | `rpm`, `yum` | `.rpm` |
| Debian 계열 | Debian, Ubuntu | `dpkg`, `apt-get` | `.deb` |

예를 들어 `httpd-2.4.6-93.el7.centos.x86_64.rpm`에서 `httpd`는 패키지명, `2.4.6`은 버전, `93`은 릴리스, `x86_64`는 아키텍처입니다.

## 2. RPM과 yum

| 명령 또는 옵션 | 역할 |
| --- | --- |
| `rpm -qa httpd` | 설치된 패키지 중 `httpd` 확인 |
| `rpm -i` / `-U` / `-e` | 설치 / 업그레이드 / 제거 |
| `rpm -V httpd` | 설치된 패키지 파일 검증 |
| `yum install` / `remove` | 패키지 설치 / 제거 |
| `yum search` / `info` | 패키지 검색 / 정보 확인 |
| `yum history` | 패키지 작업 이력 확인 |

`rpm -V`의 웹 자료 예시에서 `S`, `5`, `T`는 각각 크기, 체크섬, 수정 시간의 변경을 나타냅니다. 강제 설치나 의존성 무시 옵션은 문제를 일으킬 수 있으므로 웹 자료의 옵션 목록을 그대로 적용하기보다 영향을 먼저 확인합니다.

## 3. dpkg와 apt-get

| 명령 또는 옵션 | 역할 |
| --- | --- |
| `dpkg -l` | 설치된 패키지 목록 확인 |
| `dpkg -i 파일.deb` | 로컬 패키지 설치 |
| `dpkg -r 패키지` | 패키지 제거 |
| `dpkg -P 패키지` | 패키지와 설정 파일 제거 |
| `apt-get update` | 패키지 목록 갱신 |
| `apt-get install 패키지` | 패키지 설치 |
| `apt-get remove 패키지` | 패키지 제거 |
| `apt-get purge 패키지` | 패키지와 설정 파일 제거 |
| `apt-get upgrade` | 패키지 업그레이드 |

`update`는 목록 갱신이고 `upgrade`는 실제 업그레이드입니다. 웹 자료는 네트워크 기반 도구인 `yum`, `apt-get`과 로컬 패키지를 다루는 `rpm`, `dpkg`를 소개합니다.

### 학습 순서

1. `dpkg -l`로 현재 설치된 목록을 살펴봅니다.
2. 패키지 목록 갱신(`update`)과 설치된 패키지 업그레이드(`upgrade`)의 차이를 확인합니다.
3. 설치할 패키지와 필요한 변경 사항을 확인한 다음 설치 여부를 결정합니다.
4. 제거(`remove`)와 설정까지 제거(`purge`)의 차이를 확인합니다.

`update`, 설치, 제거는 시스템이나 네트워크를 사용하는 작업이므로 위 순서는 개념 확인용입니다.

> 위 설치·제거 명령의 `패키지`와 `파일.deb`는 실제 값이 아닌 자리 표시자입니다. 작업 전 대상과 변경 내용을 확인하세요.
