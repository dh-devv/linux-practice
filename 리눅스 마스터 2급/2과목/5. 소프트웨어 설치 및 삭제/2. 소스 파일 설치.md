# 소스 파일 설치

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 아카이브, 압축, 소스 설치 내용을 정리했습니다. 압축 해제와 설치는 파일을 생성·변경하므로 실습 위치와 설치 경로를 확인하세요.

## 1. 아카이브와 압축

**아카이브**는 여러 파일이나 디렉터리를 하나로 묶는 작업입니다. 압축은 데이터의 크기를 줄이는 별도의 작업이며 `tar`와 압축 옵션을 함께 사용할 수 있습니다.

| `tar` 옵션 | 역할 |
| --- | --- |
| `-c` | 아카이브 생성 |
| `-x` | 아카이브 추출 |
| `-t` | 내용 목록 확인 |
| `-f` | 아카이브 파일 지정 |
| `-v` | 처리 과정 출력 |
| `-z` / `-j` / `-J` | gzip / bzip2 / xz 사용 |
| `-C` | 대상 디렉터리 지정 |

```bash
tar -cvzf linux.tar *
tar -tzf linux.tar
```

웹 자료의 첫 명령은 현재 디렉터리의 항목을 gzip으로 압축하여 `linux.tar`로 묶습니다. 두 번째 명령은 해제하지 않고 목록을 확인합니다. 파일이 생성되므로 실습용 디렉터리에서만 실행합니다.

## 2. 압축 도구

| 압축 | 해제 | 확장자 |
| --- | --- | --- |
| `gzip` | `gunzip` | `.gz` |
| `bzip2` | `bunzip2` | `.bz2` |
| `xz` | `unxz` | `.xz` |
| `compress` | `uncompress` | `.Z` |
| `zip` | `unzip` | `.zip` |

웹 자료의 예시:

```bash
gzip -9 linux.txt
gunzip linux.txt.gz
```

압축·해제는 파일에 영향을 주므로 실습용 복사본으로 진행합니다. `bzip2 -k`는 웹 자료에서 원본을 유지하는 옵션으로 소개합니다.

## 3. 소스 코드 빌드 과정

웹 자료는 압축을 푼 소스의 일반적인 설치 순서를 다음과 같이 설명합니다.

```text
소스 압축 해제 → ./configure → make → make install
```

1. `./configure`: 설치 환경을 확인하고 빌드에 사용할 Makefile을 준비합니다.
2. `make`: Makefile을 바탕으로 소스를 컴파일합니다.
3. `make install`: 빌드 결과를 지정된 위치에 설치합니다.

모든 소스 프로젝트가 같은 절차를 사용하는 것은 아닙니다. 실제 실행 전 해당 소스의 설치 안내와 설치 경로를 확인합니다.

## 4. CMake

웹 자료는 CMake를 여러 운영체제를 지원하며 빌드 파일을 생성하는 도구로 소개합니다. 소스의 의존관계를 분석하고 다양한 플랫폼을 위한 빌드 구성을 지원합니다.
