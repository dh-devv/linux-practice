# 주변 장치 연결 및 설정

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)에서 소개한 프린터·사운드·스캐너 구성 요소를 정리했습니다. 파일 경로와 지원 장치는 환경에 따라 다릅니다.

## 1. 프린터

| 시스템 | 웹 자료의 설명 |
| --- | --- |
| LPRng | BSD 계열의 전통적인 프린팅 시스템. 스풀링과 네트워크 프린터 지원 |
| CUPS | IPP를 사용하는 프린팅 시스템. 웹 기반 제어와 인증 기능 제공 |

스풀링은 인쇄할 작업을 대기열에 두고 처리하는 방식으로 이해합니다. 웹 자료는 LPRng 설정 파일로 `/etc/printcap`, CUPS 설정 디렉터리로 `/etc/cups`를 소개합니다.

## 2. 사운드 카드

| 구성 요소 | 역할 |
| --- | --- |
| OSS | 유닉스 계열에서 사운드 카드를 제어하는 인터페이스 |
| ALSA | 리눅스의 사운드 장치 드라이버와 장치 관리 관련 구성 요소 |

웹 자료는 ALSA 설정 파일 예로 `/etc/asound.state`를 소개합니다.

## 3. 스캐너

| 구성 요소 | 역할 |
| --- | --- |
| SANE | 스캐너 등 이미지 장치를 제어하는 API |
| XSANE | SANE을 사용하는 X 윈도 기반 스캐너 프로그램 |

스캐너와 관련 명령을 사용하려면 장치와 프로그램이 해당 환경에서 준비되어 있어야 합니다.
