# 주변 장치 활용

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 프린터·사운드·스캐너 명령을 정리했습니다. 실제 인쇄나 장치 설정 변경은 장치와 다른 사용자에게 영향을 줄 수 있습니다.

## 1. 프린터 명령

### BSD 계열

| 명령 | 역할 |
| --- | --- |
| `lpr 파일명` | 인쇄 작업 요청 |
| `lpq` | 인쇄 대기열 확인 |
| `lprm 작업번호` | 대기 중인 작업 제거 |
| `lpc` | 프린터 또는 대기열 제어 |
| `lpd` | 프린터 데몬 |

예를 들어 작업을 취소할 때는 먼저 `lpq`에서 작업 번호를 확인합니다. 웹 자료의 `lpr -P 프린터 파일명`은 특정 프린터 지정 예시입니다.

### System V 계열

| 명령 | 역할 |
| --- | --- |
| `lp 파일명` | 인쇄 작업 요청 |
| `lpstat` | 프린터 대기열 상태 확인 |
| `cancel` | 인쇄 작업 취소 |

`lp -d`는 프린터를, `lp -n`은 인쇄 매수를 지정합니다. `cancel -a`는 모든 인쇄 작업을 취소하는 옵션이므로 주의합니다.

## 2. 사운드 관련 명령

| 명령 | 웹 자료의 설명 |
| --- | --- |
| `alsactl init` | 사운드 장치 초기화 |
| `alsactl store` | 사운드 카드 설정 저장 |
| `alsactl restore` | 저장한 사운드 카드 설정을 다시 읽음 |
| `alsamixer` | 텍스트 기반 오디오 제어 프로그램 |
| `cdparanoia` | 오디오 CD에서 음악 파일 추출 |

## 3. 스캐너 관련 명령

| 명령 | 역할 |
| --- | --- |
| `sane-find-scanner` | 스캐너 관련 장치 검색 |
| `scanimage -L` | 사용 가능한 스캐너 목록 확인 |
| `scanimage` | 이미지 스캔 |
| `scanadf` | 자동 문서 공급 장치가 있는 스캐너에서 여러 장 스캔 |
| `xcam` | GUI 기반 이미지 스캔 |

먼저 장치 목록을 확인하고, 실제 스캔이나 출력 파일 생성은 장치와 저장 위치를 확인한 뒤 진행합니다.

## 복습

인쇄 요청은 `lpr` 또는 `lp`, 대기열 확인은 `lpq` 또는 `lpstat`, 스캐너 목록 확인은 `scanimage -L`입니다.
