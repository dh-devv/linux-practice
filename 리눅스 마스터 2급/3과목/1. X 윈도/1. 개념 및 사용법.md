# X 윈도의 개념 및 사용법

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 X 윈도 내용을 정리했습니다. 실행 명령과 키 조합은 사용하는 환경에 따라 다를 수 있습니다.

## 1. X 윈도란?

X 윈도 시스템은 리눅스 등의 애플리케이션에 그래픽 사용자 인터페이스를 제공하는 시스템입니다. `X`, `X11`, X Window System이라고도 부릅니다. 네트워크 기반으로 동작하며 서버와 클라이언트가 같은 시스템 또는 서로 다른 시스템에 있을 수 있습니다.

## 2. X 서버와 X 클라이언트

| 구성 요소 | 역할 |
| --- | --- |
| X 서버 | 디스플레이와 입력 장치를 관리하고 클라이언트 요청을 처리 |
| X 클라이언트 | X 서버의 기능을 이용하는 응용 프로그램 |
| X 프로토콜 | 서버와 클라이언트의 메시지 교환 규약 |
| Xlib·툴킷 | X 기능을 이용해 프로그램을 만들 때 사용하는 라이브러리 |

X 서버는 화면과 입력 장치를 담당하고, X 클라이언트는 표시할 응용 프로그램이라는 점이 자주 쓰는 서버·클라이언트 이미지와 혼동되기 쉽습니다.

## 3. 실행과 출력 대상

웹 자료는 텍스트 환경에서 `startx`로 X 윈도를 시작하는 예를 소개합니다. `startx`는 환경 초기화 후 `xinit`을 호출합니다.

```bash
echo "$DISPLAY"
```

`DISPLAY`는 X 윈도 출력 대상을 나타내는 환경변수입니다. 웹 자료의 형식은 `IP주소:디스플레이번호.스크린번호`입니다. 값을 임의로 변경하면 그래픽 응용 프로그램이 원하는 화면에 연결되지 않을 수 있습니다.

## 4. 윈도 매니저·데스크톱·디스플레이 매니저

| 구분 | 역할 | 웹 자료의 예 |
| --- | --- | --- |
| 윈도 매니저 | 창의 형태와 동작을 관리 | fvwm, twm, Window Maker |
| 데스크톱 환경 | 파일 관리자, 설정 도구 등 그래픽 사용 환경 제공 | GNOME, KDE, LXDE, Xfce |
| 디스플레이 매니저 | 그래픽 로그인과 세션 시작 | GDM, KDM, XDM |

웹 자료에서는 GNOME을 GTK+ 기반, KDE를 Qt 기반 데스크톱 환경으로 비교합니다. 각 구성 요소는 같은 것이 아니므로 **창 관리 / 데스크톱 도구 / 로그인**이라는 역할을 나누어 기억하세요.
