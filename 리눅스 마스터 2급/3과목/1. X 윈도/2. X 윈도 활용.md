# X 윈도 활용

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 X 클라이언트 접근과 응용 프로그램을 정리했습니다.

## 1. X 클라이언트 접근

X 클라이언트는 X 서버에 연결해 화면에 그래픽을 표시합니다. 출력할 서버는 `DISPLAY` 환경변수로 지정합니다.

| 명령 | 웹 자료의 기능 |
| --- | --- |
| `xhost` | 호스트 단위로 X 서버 접근을 제어 |
| `xauth` | 인증에 사용할 쿠키를 관리 |

`xhost +`는 웹 자료에서 모든 클라이언트의 접속을 허용하는 예로 소개됩니다. **접근 범위를 넓히므로 실제 시스템에서 무심코 실행하지 마세요.** `xauth`는 웹 자료에서 사용자 홈의 `.Xauthority`와 인증 키를 이용하는 방식으로 설명합니다. 인증 키는 다른 사람에게 공개하지 않습니다.

## 2. X 윈도 응용 프로그램

| 분야 | 프로그램 | 역할 |
| --- | --- | --- |
| 오피스 | LibreOffice Writer, Calc, Impress, Draw | 문서, 스프레드시트, 발표 자료, 그림 |
| 텍스트 | gedit, KWrite | 텍스트 편집 |
| 그래픽 | GIMP, ImageMagick | 이미지 편집·처리 |
| 이미지 보기 | eog, gThumb, Gwenview | 이미지 확인 |
| 멀티미디어 | Totem, Rhythmbox, Cheese | 영상·음악·카메라 관련 기능 |
| 개발 | Eclipse | 통합 개발 환경 |
| 파일 관리 | Dolphin | KDE 파일 관리자 |
| 화면 캡처 | KSnapshot | 스크린샷 |

웹 자료에 나오는 프로그램은 예시이며, 현재 시스템에 모두 설치되어 있다는 뜻은 아닙니다.

## 복습

`xhost`는 호스트 접근 제어, `xauth`는 쿠키 기반 인증 관리입니다. X 응용 프로그램은 X 클라이언트로서 X 서버의 화면 출력 기능을 사용합니다.
