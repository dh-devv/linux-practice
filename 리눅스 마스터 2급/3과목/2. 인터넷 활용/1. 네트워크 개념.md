# 네트워크 개념

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 네트워크 개념을 정리했습니다. 일부 망 기술과 장비 설명은 자료에서 소개한 전통적인 예시입니다.

## 1. 통신망의 범위

| 종류 | 의미 | 예 |
| --- | --- | --- |
| LAN | 제한된 가까운 지역의 네트워크 | 건물 내부 |
| MAN | 도시권의 여러 LAN을 연결하는 네트워크 | 도시 내 연결 |
| WAN | 국가·대륙 등 넓은 지역을 연결하는 네트워크 | 원거리 네트워크 |
| SAN | 저장 장치를 위한 고속 네트워크 | 서버와 저장 장치 연결 |

웹 자료는 LAN 예로 Ethernet, Token Ring, FDDI를 소개하고, WAN 관련 프로토콜로 HDLC, PPP, X.25, Frame Relay, ATM을 소개합니다.

| LAN 기술 | 웹 자료의 매체 접근 방식 |
| --- | --- |
| Ethernet | CSMA/CD |
| Token Ring | 토큰 패싱 |
| FDDI | 토큰 패싱과 이중 링 구조 |

CSMA/CD는 매체의 사용 여부를 확인해 전송하고 충돌이 발생하면 기다렸다가 다시 시도하는 방식으로 소개됩니다. 토큰 패싱은 전송 권한을 나타내는 토큰의 흐름으로 순서를 정합니다.

## 2. 네트워크 배치와 장비

| 토폴로지 | 구조와 특징 |
| --- | --- |
| 스타형 | 중앙 장비에 연결. 확장이 쉽지만 중앙 장애가 전체에 영향 |
| 버스형 | 하나의 통신 회선을 공유. 노드가 많아지면 병목 가능 |
| 링형 | 인접 노드가 원형으로 연결 |
| 트리형 | 계층적으로 분기 |
| 망형 | 노드 간 연결과 우회 경로가 많지만 구축 비용이 큼 |

웹 자료는 LAN 카드, 리피터, 허브, 스위치, 라우터 등을 네트워크 장비로 소개합니다. 네트워크 인터페이스는 장치가 네트워크에 연결되는 지점입니다.

LAN 카드는 시스템을 네트워크에 연결하고 MAC 주소를 이용해 데이터 수신을 구분합니다. 리피터는 신호를 재생·증폭하여 전송 거리를 늘립니다. 웹 자료에는 UTP·STP 꼬임선과 광섬유도 전송 매체의 예로 제시됩니다.

## 3. 프로토콜

프로토콜은 통신을 위한 규약입니다. 웹 자료는 데이터 형식을 정하는 **구문**, 동작을 정하는 **의미**, 속도·순서를 정하는 **타이밍**을 구성 요소로 설명합니다.

| 프로토콜 | 역할 |
| --- | --- |
| IP | 네트워크 간 패킷 전달과 논리 주소 지정 |
| ICMP | IP 전달과 관련된 메시지 및 연결 확인 |
| ARP | IP 주소를 MAC 주소에 대응 |
| TCP | 연결을 수립하고 신뢰성 있는 전송을 지원 |
| UDP | 연결 수립 없이 메시지를 전송 |

TCP의 연결 수립 과정은 `SYN → SYN+ACK → ACK` 순서의 **3-way handshake**로 소개됩니다. UDP는 이 연결 수립 과정을 사용하지 않습니다.

웹 자료의 OSI 모델은 통신 기능을 7계층으로 나누어 설명하는 모델이며, TCP/IP 모델의 계층과 정확히 일대일로 일치하지는 않습니다.

## 4. IP 주소

| 구분 | IPv4 | IPv6 |
| --- | --- | --- |
| 길이 | 32비트 | 128비트 |
| 표기 | 8비트씩 나누어 점과 10진수로 표시 | 16비트씩 나누어 콜론과 16진수로 표시 |
| 통신 방식 | 유니캐스트, 멀티캐스트, 브로드캐스트 | 유니캐스트, 멀티캐스트, 애니캐스트 |

IPv4 주소의 네트워크 부분과 호스트 부분은 **서브넷 마스크**로 구분합니다. 마스크에서 1인 부분이 네트워크 부분, 0인 부분이 호스트 부분입니다.

| 전달 방식 | 대상 |
| --- | --- |
| 유니캐스트 | 한 인터페이스 |
| 멀티캐스트 | 특정 그룹의 여러 인터페이스 |
| 브로드캐스트 | 같은 네트워크 전체 |
| 애니캐스트 | 여러 후보 중 하나의 인터페이스 |

웹 자료는 애니캐스트를 IPv6의 통신 방식으로 소개합니다.

### 사설 IPv4 주소 범위

| 범위 | 주소 |
| --- | --- |
| A | `10.0.0.0` ~ `10.255.255.255` |
| B | `172.16.0.0` ~ `172.31.255.255` |
| C | `192.168.0.0` ~ `192.168.255.255` |

## 5. 도메인

도메인은 사람이 기억하기 쉽게 만든 인터넷 이름입니다. 예를 들어 웹 자료의 `domain.co.kr`은 점으로 구분된 이름이며, `kr`은 국가 최상위 도메인입니다. DNS를 이용해 도메인과 IP 주소를 조회할 수 있습니다.
