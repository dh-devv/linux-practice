# 리눅스 기술 동향

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 리눅스 동향과 관련 기술을 정리했습니다. 웹 자료에 소개된 분야와 예시를 학습하는 문서이며, 현재 시장 점유율이나 최신 동향을 주장하는 자료는 아닙니다.

## 1. 리눅스 활용 분야

| 분야 | 웹 자료의 예시 |
| --- | --- |
| 서버 | Apache, FTP, SSH, 데이터베이스 서버 |
| 데스크톱·개발 | 웹 브라우저, 오피스, 이미지 편집 및 개발 환경 |
| 모바일 | 스마트폰과 태블릿의 운영체제 |
| 임베디드 | 스마트 TV, 가전, 자동차 장치, 로봇 |

하나의 기술이 서버부터 작은 장치까지 여러 환경에서 활용될 수 있다는 점을 먼저 이해합니다.

## 2. 클러스터링

클러스터링은 여러 시스템을 네트워크로 연결해 하나의 시스템처럼 활용하는 기술입니다. 웹 자료는 실제 작업을 처리하는 **노드**와 자원을 분배·관리하는 **클러스터 관리자**를 설명합니다.

| 종류 | 목적 |
| --- | --- |
| 고계산용 HPC 클러스터 | 여러 시스템의 계산 능력을 결합. 과학 계산 등에 활용 |
| 부하분산 클러스터 | 여러 서버에 요청을 나누어 서비스 |
| 고가용성 HA 클러스터 | 장애에 대비해 서비스의 연속성을 높임 |

## 3. 임베디드 시스템

임베디드 시스템은 특정 목적을 수행하도록 하드웨어와 소프트웨어를 결합한 시스템입니다.

| 구성 | 예 |
| --- | --- |
| 하드웨어 | 프로세서, 메모리, 입출력 장치, 센서 |
| 소프트웨어 | 운영체제, 시스템 소프트웨어, 응용 소프트웨어 |

웹 자료는 목적에 맞게 최적화할 수 있고 소형·저전력 설계에 활용할 수 있다고 설명합니다. 동시에 메모리 요구량과 개발 환경, 표준화 등의 어려움도 소개합니다. 장점과 제약은 제품의 설계와 사용 환경에 따라 달라집니다.

## 복습

HPC는 **계산 능력**, 부하분산은 **요청 분산**, HA는 **서비스 연속성**에 초점을 둡니다. 임베디드 시스템은 **특정 목적**을 수행하도록 설계됩니다.
