# 리눅스 활용 기술

> [학습 웹 페이지](https://dh-devv.github.io/linux-practice/)의 서버 가상화, 클라우드, 빅데이터, 임베디드 활용 사례를 정리했습니다. 제품과 버전은 웹 자료에 제시된 학습 예시입니다.

## 1. 서버 가상화

가상화는 하나의 물리적 자원을 여러 논리적 자원으로 활용하는 기술입니다. **하이퍼바이저**는 가상 머신이 하드웨어 자원을 나누어 사용하도록 관리합니다.

```text
물리 서버의 CPU·메모리
        ↓
하이퍼바이저
        ↓
여러 가상 머신
```

| 방식 | 웹 자료의 설명 | 예시 |
| --- | --- | --- |
| 네이티브 방식 | 하드웨어에서 직접 실행하는 방식 | Xen, KVM |
| 호스티드 방식 | 운영체제 위에서 응용 프로그램처럼 실행 | VirtualBox, VMware Workstation |

웹 자료는 서버 통합, 유연한 자원 할당, 관리 비용 절감 등을 가상화의 목적으로 소개합니다. 가상화 자체만으로 장애 대응이 자동으로 완성되는 것은 아니므로 구성 목적을 구분해 이해합니다.

## 2. 클라우드 컴퓨팅

클라우드는 서버, 저장 공간, 소프트웨어 등의 컴퓨팅 자원을 네트워크를 통해 이용할 수 있게 하는 방식입니다.

| 서비스 모델 | 제공하는 것 | 웹 자료의 예 |
| --- | --- | --- |
| IaaS | 서버·스토리지·네트워크 등 인프라 자원 | Amazon EC2 |
| PaaS | 애플리케이션을 개발·실행할 플랫폼 | Google App Engine |
| SaaS | 바로 사용할 수 있는 응용 소프트웨어 | Google Drive |

웹 자료는 클라우드 구축을 위한 오픈 소스 프로젝트 예로 OpenStack, CloudStack, Eucalyptus를 소개합니다.

## 3. 빅데이터와 Hadoop

빅데이터는 기존 도구의 수집·저장·관리·분석 역량을 넘어서는 대규모 데이터를 다루는 분야입니다.

| 3V | 의미 |
| --- | --- |
| Volume | 데이터의 규모 |
| Velocity | 데이터가 생성·수집·처리되는 속도 |
| Variety | 정형·반정형·비정형 등 데이터의 다양성 |

웹 자료의 **Hadoop**은 대용량 데이터를 분산 처리하는 자바 기반 오픈 소스 프레임워크입니다. **HDFS**에 데이터를 저장하고 **MapReduce**를 이용해 분산 처리하는 예를 소개합니다.

## 4. 모바일과 임베디드 활용

| 분야 | 웹 자료의 예시 |
| --- | --- |
| 모바일 운영체제 | Android, iOS, Tizen |
| 스마트 TV | Tizen, webOS |
| 차량 | IVI(In-Vehicle Infotainment): 내비게이션, 영상·음악 등 차량 내부 정보·오락 기능 |

웹 자료는 Android와 Tizen을 리눅스 관련 모바일 활용 예로 소개하며, iOS도 모바일 운영체제 비교 대상으로 함께 설명합니다. iOS를 리눅스 기반 운영체제라는 뜻으로 혼동하지 않습니다.

## 복습

가상화는 **물리 자원의 논리적 분할**, 클라우드는 **네트워크를 통한 자원 제공**, Hadoop은 **데이터의 분산 저장·처리**, 임베디드는 **특정 장치와 목적에 맞춘 활용**으로 구분합니다.
